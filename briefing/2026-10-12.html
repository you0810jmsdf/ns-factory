CASE 01 ／ 販売幕僚

悩み起点の商品紹介文

要点悩みから入る商品紹介文のコツ

商品のスペックをただ並べても人は買わない。「洗剤を取ろうとしたら奥のストックが倒れた」のような、読者が「それ私も！」と思う困りごとを具体的に書き、その商品がどう助けてくれるかを自然につなげると、紹介文の印象がガラッと変わる、という話です。

現状分析並べ方の知見は記録済み

  • 商品ページは「結論→体験→弱点も一言→こんな人におすすめ」の順が信頼されると社内資料に記録済み
  • ボタン文言は「動詞＋得られるもの」にする知見も記録されている
  • EC商品・販売運用で販売幕僚が商品説明の下書きを継続担当している

図解

紹介文を3件選ぶ → 散らかる場面を具体的に書く → 商品がどう解決するか繋げる → 事業主確認後に公開

提言システム手帳紹介文を悩み起点で書き直す

  1. 現在の紹介文を3件選び、散らかる・探せない場面から書き直す
  2. 「結論→体験→弱点も一言→こんな人におすすめ」の順に整える
  3. ボタン文言を「動詞＋得られるもの」に変更する
  4. 書き直し後は事業主の承認を得てから公開する
いま紹介文は素材・サイズなどスペック説明が中心
→
実行後散らかる悩みの場面から入り解決を伝える紹介文になる

CASE 02 ／ 販売幕僚

アフィリエイト記事4原則

要点読まれる記事の4つのコツ

アフィリエイト（紹介して稼ぐ）記事メルマガの回では、①タイトルを工夫②2000字以上③500字に1枚写真④売り込みすぎない紹介の仕方、という4つのルールが紹介されています。

現状分析ページの型は一部整備済み

  • 商品ページは「結論→体験→弱点→おすすめ」の順で書く型が記録済み
  • ボタン文言は「動詞＋得られるもの」、スマホは44px以上と社内ルール化済み
  • 型紙PDF販売の注意点に外部リンク利用時の表示・表記確認が明記されている
  • 記事の長さ・写真の枚数・宣伝しすぎない書き方の具体ルールはまだ記録なし

図解

タイトルを工夫する → 2000字以上＋写真を500字に1枚 → 外部リンクは紹介する立場で書く → 公開前に表示・表記を確認

提言自社の紹介文・ブログにこの型を試す

  1. 型紙PDFや材料ガイドの紹介文タイトルを損得・検証型に変えてみる
  2. 文章500字ごとに写真を1枚入れて読みやすくする
  3. 外部リンクは「私はこれを使いました」等、紹介する立場の言葉にする
  4. 公開前に型紙PDF販売の注意点どおり表示・表記も確認する
いま記事・ページの長さや写真配置に明確な基準がない
→
実行後2000字・500字に［数値］写真という基準で書ける

CASE 03 ／ 広報幕僚

ポートフォリオ3〜5点厳選

要点作品は3〜5点に絞って見せる

作品をたくさん並べても、見る人は数十秒しか見てくれません。なぜそう作ったか説明できる作品だけを3〜5点選んで見せると、良さが伝わりやすくなるという考え方です。

現状分析SNS発信は運用中・選定は未着手

  • Threads・Instagram・X・LINEで発信中、投稿は一部自動・一部手動
  • 投稿カテゴリと頻度は方針化・タグも整備済み
  • 「3〜［数値］厳選」「3行説明を添える」の型はナレッジに記録済み
  • Instagram固定投稿への実際の反映はまだ記録なし

図解

全作品を並べる → 説明できるかで○×分類 → ○だけから3〜5点を厳選 → Instagram固定・スクール紹介に掲

提言作品を3〜5点に絞って固定表示へ

  1. 全作品を○×で分け、説明できる3〜5点を選ぶ
  2. 各作品に「誰のため・何のため・どこを工夫したか」の3行を添える
  3. 選んだ作品をInstagramのプロフィール固定投稿にする
  4. 同じ3〜5点をスクール紹介ページにも使い回す
いま作品が多数並び、見せたい代表作が埋もれがち
→
実行後説明できる3〜［数値］だけが固定表示で伝わる

CASE 04 ／ 広報幕僚

AIマップのコメント導線設計

要点合言葉コメントで資料を渡す型

歌舞伎町に行ったことのない人が、AIだけで観光マップサイトを作った話です。マップを見る条件を「フォロー＋いいね＋コメントに『歌舞伎町マップ』と書く」にしたら、同じ言葉のコメントがたくさん集まりました。

現状分析配布のコメント導線は未整備

  • SNSは投稿カテゴリ・頻度を方針化し、タグも整備済みだが配布導線は未設計
  • 投稿は一部自動化・一部手動で運用中
  • LINEスタンプ公募企画などコメント・応募を使う仕組みは既に進行中

図解

型紙PDF紹介を投稿 → コメントに合言葉記入 → DMでPDF送付 → フォロー増・反応アップ

提言型紙PDF配布にコメント導線を試す

  1. 型紙PDF投稿のコメント条件を「合言葉記入」に変更しテスト
  2. DM送信の手間と反応数を比較し効果を確認
  3. 好評なら新作紹介やスタンプ公募にも同じ型を展開
いま型紙PDF配布にコメント導線はまだない
→
実行後合言葉コメントで配布しフォロー増が狙える

CASE 05 ／ デジタル幕僚

AI動画指示の専門用語リスト

要点動画の指示は専門用語で狙い撃ち

AIに動画を作らせるとき「いい感じに」では演出が決まらない。「FPV」「ラックフォーカス」「ホイップパン」のようにカメラワークの名前で頼むと、狙った映像になるという投稿です。用語一覧は画像にまとまっていて保存推奨とのことです。

現状分析動画自動化はまだ検討段階

  • 講座・SNS動画の編集自動化（video-use・Remotion・OpenCutなど）は未検証の候補にとどまる
  • 商品写真を重ねて一部だけ動かす静止画アニメも、動画生成AIの代替候補として記録済み
  • カメラワーク等の指示用語リストそのものの記録は社内資料に見当たらない

図解

専門用語リストを転記 → CLAUDE.mdに追記 → AIへの動画指示に使用 → 講座・商品動画が狙い通りに

提言動画指示用語をCLAUDE.mdに登録

  1. 投稿画像の専門用語一覧を転記し、CLAUDE.mdに追記する
  2. 講座動画・商品紹介動画の指示文に用語を使い演出を安定させる
  3. video-use・Remotion等の編集自動化を検証する際も同じ用語を使う
  4. 使えた用語だけを定型の指示テンプレートとして残す
いま動画の指示は「いい感じに」など曖昧な言葉が中心
→
実行後FPVやラックフォーカス等の名前で狙った演出を指示できる
