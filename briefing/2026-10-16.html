CASE 01 ／ 作戦幕僚

AI修正の「範囲限定・確認結合」型

要点AIに直す場所だけ渡す修正術

設計図をAIに直してもらうとき、全部任せず「直してほしい部分だけ」を取り出して渡し、AIが直したら人が確認してから元に戻す方法が紹介されていました。これならAIが余計な部分を変える心配がありません。

現状分析見積・型紙AI修正は未整備

  • 見積書システムはGASで稼働中だが、AIに修正を頼む仕組みはまだない
  • 型紙PDFはCADフォルダで後方部が管理、修正範囲を区切る手順は未整備
  • AI共通頭脳連携は運用開始済みだが読み込み順の定着が課題として残る

図解

直す範囲だけ切り出す → AIに修正してもらう → 人が内容を確認 → 元のファイルに結合

提言見積・型紙修正にAI確認結合を試す

  1. 見積スクリプト1件でAI依頼範囲を限定して試行する
  2. 修正前後を見比べ、余計な変更がないか人が確認する
  3. うまくいけば型紙PDF修正にも同じ手順を広げてみる
いま修正をAIに全任せすると変更範囲が不安
→
実行後直す範囲を区切り、確認してから反映できる

CASE 02 ／ 広報幕僚

競合リフィル「4ページ/週」新作分析

要点競合リフィル「週4ページ」新作が登場

手帳メーカーの46KUMA NOTEが、1週間を4ページで使う新しいリフィルを発表しました。1日ごとに時間帯を自由に区切れる方眼と、朝昼夜などに分けられる線が特徴です。2026年11月19日発売予定です。

現状分析競合比較の仕組みはまだ未着手

  • SNSタグに#リフィル #手帳会議 #システム手帳など発信の下地は整備済み
  • 新作紹介・豆知識の投稿カテゴリと頻度は方針化済みだが競合比較枠はない
  • Threadsは初見前提・属性ワード・時間帯固定が伸びる型と把握済み
  • 競合リフィルの機能比較表を作った記録は見当たらない

図解

他社新作リフィルの情報を収集 → 4社の機能を比較表にまとめる → 自社リフィル企画のヒントにする → SNSで発信・反応を見る

提言競合比較表を企画とSNS発信に使う

  1. 46KUMA NOTE含む4社の新作を機能比較表にして自社企画の参考にする
  2. 「自分が使いたいものを作る」という理由語りの投稿型を自社でも試す
  3. 新作紹介カテゴリの投稿枠に競合動向まとめを追加する
  4. 手帳会議シーズンに合わせた発売タイミングを検討する
いま競合リフィルの新作情報は個別に見るだけでまとめていない
→
実行後［数値］の機能比較表で市場動向と自社の立ち位置が見える

CASE 03 ／ 保全幕僚

アフィリエイト禁止行為4点チェック

要点アフィリエイト禁止行為4つに注意

ASP（広告仲介会社）から届いた注意メール。①他サイトの文章・画像の盗用禁止②ブランド名の無断使用（商標）禁止③嘘の体験談禁止④検索広告の出稿条件違反禁止、の4点を守らないとアカウント停止もありうる、という内容です。

現状分析外部リンク表記の注意が一部記録

  • 型紙PDF販売ノートに「アフィリエイトや外部リンクは表示・表記を確認する」と記載あり
  • 材料ガイドは購入先・価格・在庫が変動する前提で書く方針のみで商標の扱いは未記載
  • 盗用・商標・虚偽表記・広告出稿条件を［数値］まとめてチェックする仕組みは社内資料に見当たらない

図解

  • 盗用：文章・画像を自作しているか
  • 商標：ブランド名を無断で使っていないか
  • 虚偽表記：感想は事実そのままか
  • 出稿条件：広告の規約条件を確認したか

提言型紙PDF等の表記に4点チェックを導入

  1. 型紙PDF・材料ガイドの外部リンクに出典表記ルールを追加する
  2. 商品紹介文でブランド名を使う前に商標登録の有無を確認する
  3. レビュー・体験談は誇張せず実際の感想のみ書くよう統一する
  4. 広告出稿する際は規約のNG条件を事前確認する欄を用意する
いま外部リンクや表記のルールが曖昧なまま運用している
→
実行後［数値］チェックシートで表記・商標リスクを事前確認できる

CASE 04 ／ デジタル幕僚

国産AI「Sarashina」無料公開

要点国産AI「Sarashina」無料公開

ソフトバンク系の会社が作った日本語に強いAI「Sarashina」が、誰でも無料で使えるようになりました。日本語や日本の文化を理解するのが得意なAIとされています。

現状分析複数AI活用・比較の実績あり

  • 動画編集ソフトや3D CADなど無料ツール候補を複数比較してから採用する運用をしている
  • 講座動画制作や3Dパース検討でChatGPT・Claude・Geminiなど複数のAIを使い分けている
  • 商品説明文やSNS文に特化したAIの比較は社内資料にまだ記録がない

図解

同じ商品説明文の題材を用意 → Sarashina・ChatGPT・Cl → 日本語の自然さ・手帳用語の的確さを比較 → 良い案を商品説明やSNS文に採用

提言商品説明文をSarashina含め3種で試作比較

  1. Sarashina・ChatGPT・Claudeで同じ商品の説明文を作って比べる
  2. 手帳の専門用語や日本語表現の自然さを評価基準にする
  3. 良かった案をCreema・minne等の商品説明に反映する
  4. SNS投稿文づくりにも応用できるか試す
いま商品説明文の作成AIを比較したことがない
→
実行後Sarashinaも候補に加え一番自然な文章を選べる

CASE 05 ／ デジタル幕僚

ローカルAI「AI Edge Gallery」圏外対応

要点電波がなくてもAIが使える

Googleの「AI Edge Gallery」というアプリは、AI本体をスマホの中に保存して動かす仕組みです。インターネットにつながず、機内モードや電波のない場所でも、文章作成やチャットができます。

現状分析AI活用はクラウド型中心

  • 顧客情報・取引情報は公開サイトや公開リポジトリに入れない方針を既に運用中
  • 動画制作等で使うAIツールはネット接続前提のクラウド型が中心
  • イベント会場や圏外でのオフラインAI利用の記録は社内資料になし

図解

イベント会場・圏外 → スマホ内でAIが文章下書き → 顧客情報は端末内で完結 → 帰社後に書類システムへ反映

提言圏外でも使えるAI下書きを試す

  1. スマホにAI Edge Galleryを試験導入し、工房で動作確認する
  2. 電波を切った状態での文章作成テストを行い、実用性を見極める
  3. 顧客情報を扱う会話は端末内処理に限定し、外部送信しない運用を検討
  4. イベント出店時の見積もり文等の下書きに試験的に使ってみる
いまイベント会場等の圏外ではAIを使った文章作成ができない
→
実行後圏外でもスマホ内AIで文章の下書きができる
