CASE 01 ／ 作戦幕僚

SolveCraft無料CAD活用

要点無料の3D設計ソフトSolveCraft登場

SolveCraftはブラウザで使える無料の3D CADです。スケッチから立体を作り、寸法を変えると形が自動で作り直されます。AIと連携して設計を手伝ってもらう機能もあります。

現状分析CAD活用は構想段階

  • 型紙・治具・製品のどれを設計するか事業主に確認してからツールを選ぶ方針がある
  • WEB版レザークラフトCAD×AIの実例を型紙自動生成構想の参考にしている段階
  • 治具設計・3Dプリント出力は最初の一手として試験予定、実施実績はまだない

図解

設計意図を確認 → SolveCraftで治具を試験設計 → 3Dプリントで出力テスト → バインダー金具に装着

提言バインダー金具治具をSolveCraftで試作

  1. バインダー金具用の治具をSolveCraftで設計し3Dプリントで試作する
  2. 寸法変更に強い機能を使い型紙展開の微調整を効率化できないか試す
  3. MCP経由のAI連携機能を型紙自動生成の将来構想の参考にする
  4. まずは治具1点に絞り効果を検証してから他部品へ広げる
いま治具は手作業中心で試作に時間がかかる
→
実行後SolveCraftで治具を設計し試作を短縮できる

CASE 02 ／ 販売幕僚

Patreon海外販路構築

要点Patreonで世界に手帳の型紙を売る

Patreonは海外版の「note」のようなサービスで、月額課金や有料コンテンツ販売ができます。日本語だけでなく英語で説明を付ければ、世界中の人にドル建てで型紙PDFなどを売れ、円安が追い風になるという提案です。

現状分析海外販路は未導入・国内中心

  • 現在の販売チャネルはminne・Creema・BASE等すべて国内向け
  • Pinkoiのみアジア圏向けだが欧米含む世界展開はまだ
  • 型紙PDF等デジタル商品の海外販路（Patreon）は未導入
  • 海外販路の知見はLINEナレッジとして記録済み、実行は未着手

図解

現在（国内販路）

  • minne・Creema等
  • 手数料約10%前後
  • 円建て・日本語のみ

Patreon（海外販路）

  • 英語説明文が必要
  • ドル建てで収益
  • 円安がそのまま追い風

提言型紙PDFをPatreonで海外販売開始

  1. 型紙PDF3点の説明文を英語に翻訳する
  2. Patreonのアカウントと初期設定を整える
  3. ドル建て価格を設定し円安メリットを活かす
  4. 反応を見て製作動画・講座教材にも展開を検討
いま型紙PDFは国内向け日本語販売のみ
→
実行後英語説明付きでPatreonからドル建て販売できる

CASE 03 ／ 広報幕僚

Threads曜日別投稿型

要点Threadsは曜日で読者の気分が違う

Threadsでは月曜は不安から前向きになりたい気分、水曜は現実的で数字好き、金夜〜日曜は理想や自由を求める気分になるそうです。同じ投稿でも出す曜日がズレると反応が悪くなる、という経験則の投稿です。

現状分析投稿方針はあるが曜日型は未導入

  • 投稿カテゴリと頻度はすでに方針化し、タグも整備済み
  • 投稿は一部自動・一部手動で運用中
  • 曜日ごとに投稿内容を分ける型は社内資料に記録なし

図解

月:手帳で生活を立て直す → 水:工程・数字・コストの具体 → 金夜〜日:完成品の世界観・講座案内

提言曜日別投稿型を1か月試して効果を記録する

  1. 現在の投稿10本を曜日ごとに分類し直す
  2. 月・水・金夜〜日の3パターンで投稿を割り振る
  3. 1か月間、曜日ごとの反応（いいね・保存等）を記録する
  4. 書いた投稿を使い回し、出す曜日だけ変えて再利用する
いま投稿カテゴリはあるが曜日は意識せず投稿
→
実行後曜日ごとに狙った反応を記録・比較できる

CASE 05 ／ デジタル幕僚

PDF→Markdown変換工程

要点PDFをテキストに変換してAIに渡す

PDFをそのままAI（Claude）に読ませると、画像やレイアウト情報まで処理されて読み込み量（トークン）を多く使ってしまう。先にMarkdown（文字だけのシンプルな形式）に変換してから渡すと、上限に達しにくくなるという体験談です。

現状分析PDF変換の手順は未整備

  • Markdownは社内の共通記憶庫として使っているが、PDFを変換する手順はまだ決まっていない
  • AIは全ファイルを読まず、台帳で当たりをつけて必要な文書だけ読む運用にしている
  • レシート画像をCSVに変換する仕組みはあるが、PDF→Markdown変換の記録は見当たらない

図解

補助金要項などのPDF → markitdown等で変換 → .mdファイルとして保存 → Claudeが軽く読み込む

提言何度も読むPDFはMarkdown化してから渡す

  1. 補助金要項PDFをmarkitdownでmd化し、読み込み量を減らして試す
  2. 変換したmdをOperations用テンプレフォルダに置き、使い回せるようにする
  3. 取引先資料や参考PDFにも同じ手順を広げ、読み込みコストを下げる
いまPDFをそのままClaudeに読ませ、読み込み上限に達しやすい
→
実行後PDFをmd変換してから読ませ、上限到達の頻度が減る

3D Gaussian Splatting工程表示

要点工房を3Dで撮って歩ける化

3D Gaussian Splattingという技術で、スマホで30秒撮った動画から、手元のパソコンのGPUだけで約10分、空間の3Dモデルが作れることが分かりました。工房をブラウザで歩けるショールームにする構想の実装目安になります。

現状分析3Dショールームは構想段階

  • メタバース販売チャネルの開拓や3D活用の検討はデジタル幕僚の担当範囲に含まれる
  • 工房3Dショールーム構想は以前から案として記録されているが実装の記録はまだない
  • 自社サイトやECツールは一括管理しているが3Dスキャンの着手実績はない

図解

30秒動画を撮影 → フレーム抽出15秒 → カメラ位置解決3分43秒 → 学習5分39秒で3D化

提言工房空間を試しに3D化してみる

  1. 工房の一角を30秒動画で撮り、ローカルGPUで3D化を試す
  2. 実測した所要時間をショールーム実装の目安として記録する
  3. 裁断○分・縫い○分など製作工程を秒数表で見せる発信に応用する
  4. 3Dショールームの用途をメタバース販売構想と合わせて検討する
いま工房の様子は写真でしか伝えられない
→
実行後ブラウザで歩ける3Dショールームの目安が分かる

CASE 07 ／ デジタル幕僚

本人申込アフィ短期目標設定

要点自分の申込でも報酬が出る仕組み

アフィリエイトは普通「他の人が広告経由で買う」と報酬が出ますが、「本人申込OK」の案件なら自分が買っても報酬が発生します。すぐに成果を体験したい人向けの方法として、メルマガVol.7で紹介されていました。

現状分析表示ルールのみ既存記録あり

  • 型紙PDF販売の注意点に「アフィリエイトや外部リンク使用時は表示・表記を確認する」と既に明記されている
  • 本人申込アフィリエイトの具体的な運用実績や報酬記録は社内資料に見当たらない
  • サイト・ECツールは自社管理だが、アフィリエイト経由の仕組みとは別系統で動いている

図解

自分で使うサービスを契約 → もしも経由のリンクから申込 → 本人申込OK案件なら報酬発生 → 初報酬で仕組みを確認

提言本人申込で初報酬の仕組みを確認する

  1. 型紙PDF販売で使う外部ツール契約時に本人申込OK案件がないか調べる
  2. 実際に1件試行し、報酬発生までの流れを確認する
  3. 確認した仕組みを副業ナレッジに1行で追記する
  4. 初報酬確認（短期）と記事蓄積（長期）の目標を分けて管理する
いま本人申込アフィリエイトの報酬の仕組みが未確認
→
実行後［数値］試行して報酬発生までの流れを確認できる

CASE 08 ／ 教育幕僚

FilmCraft無料動画編集

要点無料の動画編集ソフトが登場

Premiere Proにそっくりな動画編集ソフト「FilmCraft」が無料・オープンソースで公開されました。カット編集や色調整、字幕、書き出しまででき、Claudeのような AI が650個以上の命令で編集作業を直接行える「MCP」という仕組みにも対応しています。

現状分析講座動画は無料公開で検証中

  • 新規事業は受託・ライセンス販売を却下し「講座型(録画教材販売)」に決定
  • 最初の一手は無料お試し動画［数値］をYouTube公開し需要を測る段階
  • 動画編集ソフトやAI自動編集の仕組みはまだ導入していない

図解

自動録画で動画1本を撮る → FilmCraftで試し編集 → MCP対応を確認 → 講座教材として活用検討

提言講座動画の編集にFilmCraftを試す

  1. 自動録画した動画1本でFilmCraftの編集を試してみる
  2. MCP対応状況を確認し、AIによる自動編集の可否を調べる
  3. 無料お試し動画の編集作業に使い、手応えを見る
  4. 講座教材の編集作業を効率化できないか検証する
いま動画編集は手作業で行う想定
→
実行後AIが命令で編集作業を代行できる可能性
