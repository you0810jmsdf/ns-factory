CASE 01 ／ デジタル幕僚

Claude Install as app検証

要点Claudeの会話でアプリが作れて配れる

ClaudeのInstall as appという機能は、AIと話しながら作った小さなアプリを、そのままパソコンの普通のアプリとして入れて使えるという仕組みです。使う人自身のClaude契約で動くので、作った人がAPIキーの管理や利用料を負担しなくて済みます。手順や制限はまだ未確認です。

現状分析GAS中心・AIは接客窓口に限定運用

  • AI相談はHearingAI-ProxyとShowroom-AIChatの［数値］のGASで役割分担して運用中。
  • 自社サイトはGitHub Pages上で見積もり・在庫管理などのアプリを自前管理している。
  • サイト変更はローカル編集→git pushの手作業フローで、専用デスクトップアプリの仕組みはまだない。

図解

現状

  • GASでAI接客窓口を運用
  • APIキー・利用料を自社負担
  • サイト変更は手作業フロー

Install as app導入候補

  • 業務道具をデスクトップアプリ化
  • 利用者自身の契約で動く想定
  • キー管理・費用負担が減るか検証

提言無料Claude契約で動作確認し必要な権限を洗い出す

  1. 無料Claude契約でInstall as appを実際に試し、動くか確認する
  2. 見積もり補助など小さな業務道具を1つ試作して配布形を検証する
  3. 必要な権限・データの置き場所をリスト化し、持ち出し情報を確認する
  4. 講座教材化できそうか、受講者が自分の契約で動かせるか検討する
いま業務の小道具はGASや自前サーバーで作る必要がある
→
実行後受講者や自分がデスクトップアプリとして軽く使える候補が増える
