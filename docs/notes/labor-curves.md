# 見積もりの面積・工数カーブ（2026-09-05）

## 使い方

- `order_estimate/leather-order-estimate-v2.html?admin` の先頭、または `admin.html#tab=size` で構造を選ぶ。
- 点を上下にドラッグするか、表の面積・工数を入力する。矢印キーでも工数を0.05hずつ変更できる。
- 見積画面では曲線の構造選択が見積の構造に連動する。点の操作で該当サイズにも切り替える（A5とA5スリムは別）。構造未選択のまま旧式価格が残る不具合を修正済み。
- 編集は同じブラウザの端末下書きとして自動保存。通常の見積画面は公開値だけを使う。
- お客様向けに反映するには管理画面の「工数曲線をGitHubへ反映」を使う。既存のGitHubトークン設定を共用する。
- 公開設定が別画面で変更されていた場合は上書きしない。下書きをダウンロードしてから再読込して差分を確認する。
- HTMLファイルを直接ダブルクリックするとCSV取得がブラウザに拒否される。GitHub Pagesの公開URLかローカルHTTPサーバーで開く。

## 個別見積もりの控え

見積の管理者画面で「見積書＋使用カーブを保存」を押し、管理名（お客様名や見積番号）を入力するとHTMLをダウンロードする。これは共通カーブの公開保存とは別で、クラウド台帳への自動登録は行わない。

- 見積明細・金額・選択内容・日時・計算パラメータ・その見積で実際に使った構造の制御点と係数を固定保存。
- `quote-archive.js` が外部通信不要のHTMLを作成。`quote-snapshot` のapplication/jsonに機械可読データも保持。認証情報は保存対象外。
- 控えをブラウザで開けば当時のカーブと計算根拠を確認できる。共通設定の変更は保存済みファイルに影響しない。
- HTML自体は工房管理用。「お客様用に印刷／PDF保存」では工房控えの曲線・内部計算を非表示にする。HTMLそのものをお客様に渡さない。
- 廃止済み本体カラーシミュレーションのプレビューは非表示、iframeの読み込みも停止。

## 計算式と移行

旧式：工数 = `[Micro5工数 + (サイズ工数 − Micro5工数) × size_curve_factor] × work_hour_multiplier`。

新式：

1. 製作面積 A(ds) = `refill_w × refill_h / 10000 × area_mult`。
2. 工数 h = 構造ごとの曲線 `f(A)`。
3. 製作費 = `base_fee + h × labor_rate_per_hour + extra_base_cost`。
4. 仕入面積 = `round(A / (1 − leather_waste_rate), 小数1桁)`。
5. 材料費 = 仕入面積 × 革単価（内張りを別革にした場合はlining_ratioで総面積内の単価を配分）。

裏貼りの有無は構造で決まり、`area_mult` は裏貼りを含んだ総使用面積倍率。クラウゼリング選択による従来の追加×2は廃止した。リングは既存の金具代として計上する。`lining_ratio` 自体は面積追加ではない。面積倍率は既存の概算値であり、実際の型紙から面積を求めた実測値ではない。

曲線有効時は `work_hours` / `work_hour_multiplier` / `size_curve_factor` / `krause_no_multi` を価格調整に使わない。CSV列は後方互換のため残す。曲線取得に失敗した場合は従来工数で参考試算し、見積画面に未取得表示と再読込ボタンを表示する。

曲線初期点は既存のサイズ寸法と旧式の工数から移行した値。手縫い・ミシンの実測比較値ではない。価格合わせのために工数を変える場合は、手縫い実測・時給・基本料との整合を確認する。A5スリムは `kouhou-room/ring-standards.html` と同じ110×210mm。ユーザーの「A6スリム」はA5スリムの意図と確認済み。

## データ仕様

正本は `order_estimate/labor-curves.json`。

```json
{"version":1,"curves":{"構造ID":[{"area":0.4536,"hours":1,"label":"Micro 5"},{"area":3.108,"hours":6.85,"label":"A5"}]}}
```

- 各構造2〜32点、面積は正の有限値・厳密昇順、工数は非負・非減少。
- 構造IDはbrand-price.csvのbrand_idに一致させる。設定取込では登録済み構造の欠落を拒否する。
- PCHIP（単調3次Hermite）で各点を補間。区間係数は `h=a+b·t+c·t²+d·t³`、`t=A−区間開始面積`。
- 最初の点より小さい面積は原点と最初の点の比例線、最後の点を超える面積は最後の接線で外挿。
- 係数は点から再計算し、別の係数正本を持たない。
- 共通評価：`labor-curve-model.js`。共通編集・保存：`labor-curve-editor.js`。
- 見積のサイズカード・合計・管理画面の価格表が同じ評価関数を使用する。
- 管理画面のCSV編集で寸法が変わると見積側もその寸法を読み込む。ラベル付き曲線点の座標は校正用データとして固定されるため、必要なら表から変更する。

## 2026-09-05 追加料金・材料納期

- 同革の内張りがある構造では `lining_skiving_fee`（初期3000円）を冊数分加算。別革・内張りなしは加算しない。
- リング実在庫が必要数に足りない場合だけ `ring_order_shipping_fee`（初期500円）を注文単位で加算。入荷予定数は実在庫に数えない。
- 両料金は税込の別途加算で、通常価格の割引・100円単位丸め後に加える。管理画面の設定から編集可能。
- 全対応リングを表示。`hard_to_source` は在庫管理の色別フラグ。実在庫がない入手困難色は要相談として選択不可。在庫があれば通常選択可能。
- 価格未登録のリングは参考価格・要確認表示。色別差額はリングCSVの実額を使う。
- 納期は材料取寄せあり2〜4週間、在庫がそろえば7日程度。不明な在庫は確認後確定、入手困難品は個別相談。画面・見積書・メール文面・保存控えに反映。
- `estimate-fulfillment.js` を共通判定に使用。追加試験: `tools/test_estimate_fulfillment.cjs`、`tools/test_ring_difficulty.cjs`。曲線ブラウザ試験にも料金差額・見積書・納期を追加。
