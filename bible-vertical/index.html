使い方マニュアル（バイブル 週間バーチカル印刷ツール）

■ 基本の流れ

  1. 「印刷モード」で 日付あり／なし と 言語 を選ぶ
  2. 日付ありは 期間（開始日〜終了日） にかかる週をすべて（最大60週）。日付なしは 週数（枚数）
  3. 用紙面（表面／裏面）を選んでプレビュー。PCは「印刷」、スマホは「PDFを生成」
  4. 「印刷モード」の 用紙 で印刷する用紙を選べます（選んだ用紙の説明はボタンの下に出ます）
  5. 印刷ダイアログで A4縦・「実際のサイズ（100%）」 を選ぶ

■ 日付なしモードについて

  • 日付・週番号・月・祝日を印刷せず、日付欄にデジタル風「8」の薄い透かしだけ出します。なぞる・塗って日付にします
  • 曜日は「週開始」で選んだ並びで印刷します（月曜始まり／日曜始まり）。曜日も自分で書きたいときは「表示要素」の「曜日」をOFF
  • 年の途中からでも、使わない週があっても無駄になりません

■ 週間バーチカルの見方

  • 見開き1週間です。左ページに4日（月〜木）、右ページに3日（金〜日）とMEMO列。ページの左端に時刻の列があります
  • 「時間軸（バーチカル）」で 開始時・終了時 を選びます。6〜24時なら1時間が約8mm。0〜24時の全24時間にもできます（夜勤・早朝向け）
  • 30分の点線と、3時間ごとの太線は、ボタンで入り切りできます
  • 最初の紙の表と最後の紙の裏は、罫線だけのメモページになります（見開きの左右がそろうため）

■ 用紙と面付け

  • A4を 縦向き に使い、バイブル（95×170mm）を2列×1段に2面並べます。周囲の余白（カット線の外側）は切り落とします
  • 表面に奇数番の週、裏面に偶数番の週が並びます。両面印刷（長辺綴じ）で切り分けると、各紙の表裏が 1・2週目、3・4週目 … と対になります（1枚の用紙で4週分）
  • 穴は6穴（上端から 18.5 / 37.5 / 56.5 / 107.5 / 126.5 / 145.5 mm、綴じ側の端から5mm。バイブル週間・日次の旧ツールと同じ位置（実機印刷で2mm上げた値））
  • ※ 両面の面付けは実物での組み立て確認が済んでいません。まず1枚で試してから本番印刷をおすすめします

■ 困ったとき

  • サイズが合わない → 用紙の向き（横）と印刷倍率100%を再確認
  • iPhone/iPadでレイアウトが崩れる → 「PDFを生成」を使用
  • 不具合・要望 → 右下の「改善要望」ボタン
