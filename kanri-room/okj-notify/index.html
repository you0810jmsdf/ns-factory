BTC/JPY 通知設定

GitHub Actions で OKJ の BTC/JPY と GMO BTC_JPY の市場データを取得し、ntfy.sh 経由で iPhone へ通知します。
⚠ cron は15分ごとの設定ですが、GitHub は定期実行を大幅に間引きます。実測では1日7〜8回・間隔の中央値148分・最長5.7時間（2026-08-26〜09-07・実行記録の全件集計）。リアルタイム性は期待できません。

読み込み中…

通知先（ntfy.sh）

iPhone 側 ntfy アプリで購読中のトピック。変更時は iPhone 側も再購読が必要です。

英数 / _ / - のみ。6〜64文字。
4 = high（推奨）、5 = max（音強制）。

円幅トリガー（band_yen）

10万円帯のように、帯を跨いだら通知。前回通知価格から帯番号が変わったら発火。

有効化 OFF にすると円幅トリガーは発火しません。
推奨: 100,000（10万円）。範囲: 1,000〜100,000,000。

%幅トリガー（band_percent）

前回通知時の価格から ±X% 動いたら通知。閾値は通知都度に更新（band方式）。

有効化 OFF にすると %幅トリガーは発火しません。
推奨: 1.0%。範囲: 0.1〜50.0。

急落・急騰トリガー（velocity）

GMOコイン BTC_JPY（レバレッジ）の確定15分足で、直近15分・1時間・4時間の変化率が閾値を超えたら通知。状態が変わった時だけ鳴り、再通知は間隔を空けます。

有効化 OFF にすると急落・急騰トリガーは発火しません。
既定 2.0。範囲 0.5〜20。
既定 3.0。範囲 0.5〜30。
既定 5.0。範囲 0.5〜50。
既定 60。同じ状態が続く間は鳴りません。

日足の局面転換（regime）

日足の終値と移動平均・その傾きから「上昇局面／横ばい／下落局面」を判定し、切り替わった時だけ通知。5年検証で SMA100 が最も安定。

有効化 OFF にすると局面転換トリガーは発火しません。
既定 200。範囲 20〜300。100だと年15回も切り替わり「局面」と呼べないため、200に較正（年4回・2026-09-08実測）。
既定 30。移動平均が何日前より上なら「上向き」とするか。

4時間足クロス（cross_4h）

4時間足の短期SMAが長期SMAを上抜け（ゴールデン）／下抜け（デッド）した時に通知。
⚠ この条件で売買しても優位性は確認できていません。GMO BTC_JPY の8年分（2018-09〜2026-09）で、学習期間 2018-09〜2023-01 だけでパラメータを選び、検証期間 2023-01〜2026-09 で答え合わせした結果、持ちっぱなしを上回った設定は45通り中0通りでした（現行 25/75＋12/200 の検証期間の翌日勝率 52.1% は、同期間の全日ベースライン 52.3% を下回る）。相場の向きを知る道具として使い、売買の根拠にはしないでください（2026-09-07 実測）。

有効化 OFF にするとクロス通知は発火しません。
既定 25。短期＜長期。12だと年21回鳴り、最短0.7日で往復するダマシを含む。25なら年15回・最短2.8日（2026-09-08実測）。
既定 200。

日足クロス（cross_daily）

日足の短期SMAが長期SMAを上抜け／下抜けした時に「今が買いです／今が売りです」と通知。4時間足より遅いぶん、拾うのは大きな転換だけ。実測（GMO BTC_JPY・過去1年）: 25/75 は7回、4時間足12/200 は21回、日足50/200 は1回。
⚠ 4時間足クロスと同じく、この条件で売買する優位性は確認できていません（上の注意を参照）。8年分の実測では、該当区間50回のリターンの中央値は +0.0%、天井を付けるまで中央値6日でした。

有効化 OFF にすると日足クロスの通知は発火しません。
既定 25。短期＜長期。
既定 75。教科書どおりの「ゴールデンクロス」にするなら 50/200（ただし過去1年で1回しか出ていない）。

毎朝の状況サマリー（summary）

4時間足・日足それぞれの向き／直近いつ切り替わったか／過去1年の回数をまとめて通知します。相場が動かない日でも状況が分かります。送る時刻の設定は workflow の cron 側（0 21 * * * ＝ 06:00 JST）。
⚠ この時刻に必ず届くわけではありません。GitHub の定期実行は間引かれ、2026-09-08 の初回は発火しませんでした。確実に毎朝届かせるには外部から起動する構成が必要です。

有効化 OFF にすると朝のサマリーは届きません（クロス通知は別途届きます）。

値動きの荒さ（volatility）

4時間足のATRが過去の分布の上位に入った／戻った時に通知。

有効化 OFF にすると荒さ通知は発火しません。
既定 14。
既定 500（4時間足で約83日）。
既定 98（上位2%に入ったら「荒い」）。80は上位20%＝珍しくなく年58回鳴る。98なら年14回（2026-09-08実測）。

板の薄さ（spread）・取引所ステータス（status）

GMOの最良気配の差（スプレッド）が閾値以上になった時、および取引所がOPEN以外になった時に通知。

スプレッド通知を有効化 平常時のBTC_JPYは約1bps。
既定 5.0（1bps＝0.01%）。
既定 120。
取引所ステータス通知を有効化 メンテナンス等でOPEN以外になったら通知。

RSI トリガー（rsi）

指定した時間足の RSI が買われすぎ / 売られすぎゾーンに入った瞬間に通知（ゾーン遷移時のみ発火）。

有効化 OFF にすると RSI トリガーは発火しません。
OKJ API がサポートする粒度のみ。推奨: 1時間足。
標準は 14。範囲: 2〜50 の整数。
2〜50 の整数で入力してください。
推奨: 70。範囲: 50〜100。oversold より大きい値である必要があります。
50〜100 かつ oversold より大きい値で入力してください。
推奨: 30。範囲: 0〜50。overbought より小さい値である必要があります。
0〜50 かつ overbought より小さい値で入力してください。

MACD トリガー（macd）

指定した時間足の MACD とシグナルの交差方向が変わった瞬間に通知（signal_cross 方式）。

有効化 OFF にすると MACD トリガーは発火しません。
OKJ API がサポートする粒度のみ。推奨: 1時間足。
標準は 12。範囲: 2〜50 の整数。slow より小さい値である必要があります。
2〜50 かつ slow より小さい整数で入力してください。
標準は 26。範囲: 3〜100 の整数。fast より大きい値である必要があります。
3〜100 かつ fast より大きい整数で入力してください。
標準は 9。範囲: 2〜50 の整数。
2〜50 の整数で入力してください。
MACD とシグナルの交差方向が変わったら通知（固定）。

Fear & Greed トリガー（fear_greed）

alternative.me の Crypto Fear & Greed Index。極端ゾーンに入った瞬間だけ 1 回通知。

有効化 OFF にすると Fear & Greed トリガーは発火しません。
推奨: 75。範囲: 50〜100。extreme_fear より大きい値である必要があります。
50〜100 かつ extreme_fear より大きい値で入力してください。
推奨: 25。範囲: 0〜50。extreme_greed より小さい値である必要があります。
0〜50 かつ extreme_greed より小さい値で入力してください。
