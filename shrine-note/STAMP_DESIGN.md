# 御朱印スタンプ帳（設計・2026-10-12）

目的：参拝した神社を記録し、スタンプラリーのように続けたくなる仕組みにする。公開してよい。

## 決まっていること（事業主決定）
- 方式A：まず「端末の中だけの記録」＋「自分のSNSへ共有」。将来「みんなのギャラリー」へ広げられる形にする
- 参拝の記録は「参拝した」ボタンで本人が押す（位置情報は使わない・会員登録なし・サーバーへ送らない）
- 事業主自身の御朱印の写真は、見本・SNS動画に使ってよい（公開リポジトリには置かない。投稿は毎回許可）

## 記録の形（localStorage `shrine-note-stamps-v1`）
`{ v: 1, visits: [ { shrineId, visitedAt: 'YYYY-MM-DD', photoId: null, shareOk: false } ] }`
- `photoId`：写真は IndexedDB（端末内）に置き、ここには ID だけ持つ（第3弾）
- `shareOk`：将来、公開してよいかを本人が選ぶための欄（いまは常に false）

## 段階
| 弾 | 内容 | 状態 |
|---|---|---|
| 1 | 記録（stamps.js）・カードの「参拝した」・地図の光を朱色に・参拝 n／全体 | 実装済み |
| 2 | スタンプ帳の画面・バッジ（1/10/30/50/100社・地方ごとの制覇） | 実装済み |
| 3 | 御朱印の写真（端末内）・共有用の画像（canvas）・OS の共有画面 | 実装済み |
| 4 | 記録の書き出し・読み込み（スマホを替えるとき） | 実装済み |
| 5 | 2つの導線（教育幕僚室・デジタル幕僚室のカード）・バナー | 実装済み（利用イメージ動画は別作業） |

## 将来のギャラリー（今は作らない）
審査（公開前の確認）・削除の窓口・本人の同意の記録・撮影禁止の神社への注意が要る。サーバーが必要になる時点で、改めて設計する。

## 注意
- 神社によって撮影・投稿を禁じている。画面に「神社の案内に従ってください」と出す
- 写真の位置情報（EXIF）は、共有用の画像を作るときに消える（canvas で描き直すため）

## 英語版（2026-10-12 開始・2026-10-16 全件完了）
- 訳文は `shrine-note/i18n/en.json`（日本語の記述の範囲だけを訳す。出典・「要確認」の状態は日本語版を引き継ぐ）。神社102社・神様128柱すべて英訳済み
- 切り替えは、設定メニューの「English」／「日本語」。`?lang=en` でも開ける（選んだ言語は端末に保存）。en.json は no-cache で読む（更新がすぐ反映される）
- 英語表示の範囲：神社カード・神様のページ・系譜図・絵巻・経路の案内・宿/名産の枠・探す窓・スタンプ帳・バッジ・通知・設定・同意画面・フッター・掲載基準（`criteria-en.html`）
- 日本語のまま残る：出典の書名・楽天の商品名と宿名（外部データ）・神様の日本語名（英語名の下に併記）
