# 記事の基準（学術的な記録として）

## 原則
1. **事実・伝承・推測を分けて書く。** 「〜とされる」「〜と伝わる」「（筆者推測）」を明示。
2. **出典を必ず付ける。** 本文末に番号付きで、資料名・発行者・URL・閲覧日。
3. **一次資料を優先。** 神社公式 > 神社本庁・自治体・文化庁（国指定文化財等データベース）> 古典（延喜式神名帳、風土記）> 事典・学術書 > 観光サイト・個人ブログ。観光サイトのみの情報は「要確認」を付ける。
4. **同名・異説を隠さない。** 祭神・創建年・読みが資料で異なる場合は併記する。
5. **宗教的中立。** 信仰を否定も勧誘もしない。ご利益は「〜と信じられている」と書く。
6. **撮影・参拝作法の注意。** 境内撮影の可否、ご神体・社殿内の撮影禁止などを現地表示に従う旨を記載。
7. **生成物の限定。** AIが書いた下書きは、必ず上記資料で人が（または別の調査工程で）裏取りする。裏取り前の記述は公開しない。

## 記録項目（必須）
神社名／読み／所在地／御祭神／社格（式内・旧社格・別表神社等）／創建・由緒／主な行事／文化財指定／アクセス・駐車場／御朱印の有無と頒布場所／情報確認日

## 表記
- 神名は初出で読みを（例: 稚産霊命（わかむすびのみこと））
- 年代は和暦（西暦）、旧暦は旧暦と明記
- 距離・所要時間は出典の日付を添える（変わりやすい情報）
