# 神社巡りノート（教育幕僚 担当）

全国の神社の魅力と巡拝に役立つ情報を、note に「学術的な記録」として蓄える企画。
夫婦での日本一周の下調べ（グルメ・宿）を兼ね、アフィリエイトと連動させる。

- 担当: 教育幕僚（精神教育・カタカムナ担当。教育幕僚室 `hitsuki/`）
- 公開先: note（本文はここで下書き→note に貼付）
- 関連: 日月神示アーカイブ `hitsuki/` とは相互リンクする（千葉の神社は `hitsuki/chiba.html` と連携）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `STYLE.md` | 記事の基準（出典・事実と伝承の区別・表記）|
| `TEMPLATE.md` | 記事テンプレート（コピーして使う）|
| `AFFILIATE.md` | アフィリエイト運用と法令（PR表記）|
| `registry.json` | 記事台帳・巡拝候補（地域別、状態管理）|
| `articles/NNN-*.md` | 記事本文の下書き |

## 進め方（1記事のサイクル）

1. `registry.json` から対象を選び、状態を `researching` にする
2. 一次資料（神社公式・神社本庁・自治体・文化庁・延喜式等）で調査。TEMPLATE に沿って下書き
3. 事実確認チェック（STYLE.md 末尾）→ `drafted`
4. グルメ・宿欄を作り、PR表記を入れる（AFFILIATE.md）→ note へ貼付 → `published` と note URL を台帳へ
5. 現地訪問後は「参拝記」欄を追記し、情報の確認日を更新

## 優先順（案）

1. 千葉・印西周辺（現地確認しやすい。日月神示アーカイブと連携）
2. 一宮・勅祭社・式内大社など「基準になる社」を地域別に
3. 日本一周ルート順（夫婦旅の実行に合わせて、訪問前に下調べ記事→訪問後に追記）


## 特集ビジュアル「夜の日本列島」（`map/`）

神社巡りノートの入口。夜の日本列島を斜めから見下ろし、特集した神社の光を選ぶと、その神社へ徐々にズームして、写真 → 項目リストの順に現れる。祭神から古事記・日本書紀の神話、同じ神様を祀る別の神社へたどれる。

- 公開URL: https://you0810jmsdf.github.io/ns-factory/shrine-note/map/ （`?s=katori` のように神社IDを付けると、その神社へ直接飛ぶ）
- 方式: three.js（自前の夜景シェーダー）＋国土地理院の標高タイルを1枚にまとめた高さ画像（約110KB）。無料で完結し、課金は発生しない。

### 構成

| ファイル | 役割 |
|---|---|
| `map/index.html` / `map/map.css` / `map/map.js` | ページ本体（描画・操作・写真・項目リスト・系譜図・現在地の光の筋） |
| `map/data/heightmap.png` | 標高（8bit。標高m = (v/255)² × 3776。海 = 0） |
| `map/tools/build_heightmap.py` | 国土地理院の標高タイル（dem_png・z7）から `heightmap.png` を作る |
| `map/vendor/three.module.min.js` | three.js r160（MIT。`THREE-LICENSE.txt` を同梱） |
| `shrines.json` | 神社（位置・祭神ID・由緒・見どころ・アクセス・写真・出典）。ビジュアルはこれを読む |
| `deities.json` | 神様（古事記・日本書紀の表記、系譜、神話の場面、出典） |
| `assets/generated/LOG.md` | AI生成画像のプロンプト・生成日・ツールの記録 |

### 操作

- PC: 左ドラッグ = 3Dで回す（向き・傾き）／右ドラッグ（または Shift+左ドラッグ）= 列島を動かす／ホイール = 寄り引き
- スマホ: 1本指 = 3Dで回す／2本指 = ドラッグで列島を動かす・ピンチで寄り引き・ひねりで向き
- 神社の光（または下のチップ）をタップ → 寄っていき、写真が夜空に浮かび、続いて項目リストが出る
- 「現在地から光の筋」: 現在地（GPS）から神社までの**道路（車）の経路**を光の筋で描き、先頭の光が道路を高速で走る。道路の経路は外部の無料公開サーバー **OSRM**（router.project-osrm.org）に問い合わせる。**同意画面で「同意」を押したときだけ**、現在地と神社の座標を送る（この特集では保存しない）。「送らずに直線で見る」を選ぶ、または取得に失敗した場合は、地図上の最短（大圏）の直線にする（理由を画面に表示）。電車・バスは含まない。所要時間に渋滞は含まない
- OSRM の公開サーバーは「デモ用」で、混雑時は止まることがある。本格運用で安定させたい場合は、自前のサーバーか有料の経路APIへ切り替える（要・費用の見積もり）

### 神社を増やす手順

1. `shrines.json` の `shrines` に1件足す（`id`・`name`・`reading`・`lat`・`lon`・`deity_ids` など）。位置は国土地理院地図で社殿を目視確認する。
2. 祭神が `deities.json` に無ければ足す（古事記の表記・巻と通称の段名・親子・神話の場面）。出典は `sources` に足し、`src` で参照する。
3. 事実・伝承・推測は `type`（`fact` / `tradition` / `guess`）で分ける。一次資料で確認できない項目は `status: "要確認"` にする（画面に「要確認」が出る）。
4. 写真は権利が確認できるものだけ。`photo` を `{ "kind": "photo", "src", "credit", "license", "source_url" }` にする。無ければ `{ "kind": "placeholder" }` のまま。
5. ローカルで `py -m http.server` などを立て、`map/index.html?s=<id>` で確認 → push。

### 出典・権利

- 標高: 国土地理院「標高タイル」（https://maps.gsi.go.jp/development/ichiran.html ）を加工して作成。高さは強調し、近景の細かな起伏は演出用のノイズ（実際の地形ではない）。画面右下に出典を表示。
- 古事記・日本書紀・古語拾遺: 原文（パブリックドメイン）の短い引用のみ。版は中文維基文庫の校訂本文（検索による確認で、全文の校合は未了）。現代語訳・注釈書の文章は引用しない。段名は便宜上の通称。
- 写真: 現在は全社プレースホルダー。AI生成画像は0枚（`assets/generated/LOG.md` 参照）。画面には「AIによるイメージ図」と明記する仕組みがある。
- 食・宿の欄: 「PR枠」のみでリンクなし（提携先が決まるまで。AFFILIATE.md に従う）。
- 道路の経路: OSRM（Open Source Routing Machine）の公開サーバーの結果。地図データは OpenStreetMap contributors（ODbL）。
- 日月神示・カタカムナは、この特集の古事記の体系には混ぜていない（記述する場合は別枠で由来を明示する）。
- 公開前の注意: 裏取り前の項目が残るため、`map/index.html` は `noindex`（検索に出さない）にしてある。確認が済んだら外す。
