# 神社巡りノート（教育幕僚 担当）

全国の神社の魅力と巡拝に役立つ情報を、note に「学術的な記録」として蓄える企画。
夫婦での日本一周の下調べ（グルメ・宿）を兼ね、アフィリエイトと連動させる。

- 担当: 教育幕僚（精神教育・カタカムナ担当。教育幕僚室 `hitsuki/`）
- 公開先: note（本文はここで下書き→note に貼付）
- 関連: 日月神示アーカイブ `hitsuki/` とは相互リンクする（千葉の神社は `hitsuki/chiba.html` と連携）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `STYLE.md` | 記事の基準（出典・事実と伝承の区別・表記）|
| `TEMPLATE.md` | 記事テンプレート（コピーして使う）|
| `AFFILIATE.md` | アフィリエイト運用と法令（PR表記）|
| `registry.json` | 記事台帳・巡拝候補（地域別、状態管理）|
| `articles/NNN-*.md` | 記事本文の下書き |

## 進め方（1記事のサイクル）

1. `registry.json` から対象を選び、状態を `researching` にする
2. 一次資料（神社公式・神社本庁・自治体・文化庁・延喜式等）で調査。TEMPLATE に沿って下書き
3. 事実確認チェック（STYLE.md 末尾）→ `drafted`
4. グルメ・宿欄を作り、PR表記を入れる（AFFILIATE.md）→ note へ貼付 → `published` と note URL を台帳へ
5. 現地訪問後は「参拝記」欄を追記し、情報の確認日を更新
