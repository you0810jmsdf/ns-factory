# アフィリエイト運用

## 使う候補
- 宿: 楽天トラベル、じゃらん、Booking.com 等（各ASPの規約で note への掲載可否を必ず確認）
- グルメ・名産: 楽天市場、食べログ・ぐるなび等の予約系（提携条件を確認）
- 旅の本・御朱印帳: 楽天ブックス、Amazon
- 既存資産: 楽天アフィリエイト（`保全部/.env`、`affiliate-links.json` の運用を踏襲。APIキーはチャットに貼らない）

## ルール（景品表示法 ステルスマーケティング規制・2023-10-01施行）
1. アフィリエイトリンクを含む記事は**冒頭に「PR」「広告を含みます」**を明記する（リンク直前にも）。
2. 神社の解説（第1〜6節）と広告欄（第7・8節）を**見出しで分離**し、解説の中立性を保つ。
3. 実際に利用していない宿・店を「おすすめ」と断定しない。未訪問は「候補」と書く。訪問後に体験記へ更新。
4. 価格・空室・営業時間は変動するので取得日を明記し「最新は公式で確認」と添える。
5. note の規約・各ASPの規約（リンク形式・禁止表現・ポイント操作）を記事ごとに確認する。
6. 費用が発生する処理（有料API等）は事前に金額を見積もって承認を得る。

## 宿の掲載設計（2026-10-12 事業主決定A：N's factory の既存の楽天アフィリエイトIDを使う）
- ⛔ もしも（mekiki_note・目利きノート名義）は使わない。副業と N's factory の収益・アカウントを混ぜない。
- 対象は**楽天トラベル**から開始。飲食は宿が動いてから別に決める（提携先・条件は未確認）。
- 状態は3段階：`candidate`（未訪問・候補）→ `visited`（訪問済み・体験記）→ `hidden`。`candidate` は「おすすめ」と書かず「候補」と書く（ルール3）。
- データは `shrine-note/stays.json`（未作成・申請の可否が確定してから作る）。1社につき `{shrine_id, name, area, url, status, fetched_at}`。`url` は楽天の管理画面で発行したトラッキング付きリンクだけ（直リンクは報酬が付かない）。
- 表示：神社カードの末尾に「宿の候補（PR）」枠。枠の先頭に「PR・広告を含みます」、リンクは `rel="sponsored noopener"`、末尾に「料金・空室は変動します。最新は楽天トラベルで確認（取得日：○○）」。解説（第1〜6節）とは見出しで分ける。
- 申請前（いま）は枠もリンクも出さない。リンクのない「PR枠」の文言だけが先に公開されないようにする。

## 楽天トラベルの条件（2026-10-12 公式ガイド https://travel.rakuten.co.jp/affiliate/guide/ を実読・N's factory のIDでログイン済みの画面から到達）
- 国内宿泊は成果対象。報酬率は利用金額の1％（レンタカー以外）。成果は「予約日から翌々月末までに利用（チェックアウト）完了」したものだけ。
- 禁止：SNS投稿での宿泊施設画像の使用・API画像のSNS投稿の自粛／条件を省いた金額だけの表示／画像だけからの誘導（テキストリンク併用が必須）。
- ⛔ 神社巡りノートでは、金額を書くなら条件（人数・日付・取得日）を併記する。画像を使うならテキストリンクも添える。SNSの投稿には宿の画像を使わない。
- 多言語サイト（travel.rakuten.com）は2022-05-31から成果対象外。日本語サイトのリンクだけ使う。
- 提携・申請の要否はガイドに明記なし（要・リンク作成ツールでの実機確認）。

## Obsidian の蓄積ノウハウの反映（2026-10-12・出典は `LINE\enriched\` の各ノート）
> 神社の解説の中立性が最優先。以下は**宿の枠（第7節）だけ**に適用し、解説（第1〜6節）には持ち込まない。数字（2000字・500字に1枚など）は配信元の目安で効果は未検証（確信度：中）のため、宿の枠には適用しない。
| 出典 | 宿の枠への使い方 |
|---|---|
| 記事作成の鉄則 Vol.6（宣伝誘導をしない） | リンク文言は「楽天トラベルで探す」「候補として」の**紹介する立場**。「今すぐ予約」「最安」などの誘導は使わない（ステマ規制の観点でも安全側） |
| 口コミで紹介の切り口を決める | 宿の一言は「喜ばれる点3つ＋最多の不満1つ」＋「向かない人」を正直に書く。⛔ 口コミの原文は転載しない（著作権）。要約は自分の言葉で |
| 心得21か条 | 70点でも公開し、うまくいった型を育てる→まず3社で型を作って確認する。「クリックされない→見せ方を変える／クリックされるのに予約されない→宿の選び方を見直す」で切り分ける。広告と分かる表記は必須 |
| カテゴリ選び Vol.4（イベントカテゴリ） | 紅葉・初詣・七五三など参拝の季節に合わせて宿の枠の見せ方を変える。楽天のセール（3・6・9・12月）や5・0のつく日は条件を明記してから触れる（金額だけの表示は禁止） |
| 目標の逆算 Vol.3 | 報酬は1％。1泊1万円の予約で100円なので、収益より**読者の利便**が主目的。収益の数字目標は置かない |
- 計測：楽天アフィリエイト管理画面のレポート（クリック・成果）を月1回確認し、成果は「承認」と「翌々月末までの利用完了」で見る。
- 飲食店は楽天のAPIに無い。別ASP（ホットペッパー・ぐるなび等）は未調査で、宿が動いてから検討する。

## 事業主が楽天の管理画面で確認する項目（実施者：事業主・私は代行不可）
