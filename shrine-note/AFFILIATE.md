# アフィリエイト運用

## 使う候補
- 宿: 楽天トラベル、じゃらん、Booking.com 等（各ASPの規約で note への掲載可否を必ず確認）
- グルメ・名産: 楽天市場、食べログ・ぐるなび等の予約系（提携条件を確認）
- 旅の本・御朱印帳: 楽天ブックス、Amazon
- 既存資産: 楽天アフィリエイト（`保全部/.env`、`affiliate-links.json` の運用を踏襲。APIキーはチャットに貼らない）

## ルール（景品表示法 ステルスマーケティング規制・2023-10-01施行）
1. アフィリエイトリンクを含む記事は**冒頭に「PR」「広告を含みます」**を明記する（リンク直前にも）。
2. 神社の解説（第1〜6節）と広告欄（第7・8節）を**見出しで分離**し、解説の中立性を保つ。
3. 実際に利用していない宿・店を「おすすめ」と断定しない。未訪問は「候補」と書く。訪問後に体験記へ更新。
4. 価格・空室・営業時間は変動するので取得日を明記し「最新は公式で確認」と添える。
5. note の規約・各ASPの規約（リンク形式・禁止表現・ポイント操作）を記事ごとに確認する。
6. 費用が発生する処理（有料API等）は事前に金額を見積もって承認を得る。
