カタカムナ80首と古事記

カタカムナウタヒの80首に、古事記の神さまの名前を重ねて読んだ人たちがいます。その「重ね読み」を、渦巻きの図と一緒にたどってみましょう。

先にお断り：これは解説者が当てた「対応づけの解釈」を整理したものです。対応が事実だとは主張しません。

BEFORE YOU READ

読む前に知っておくこと

  • 古事記の神名・地名に当てられているのは、80首のうち45首。残りは「対応なし」と明記された首、神器だけの首、資料に記述が見つからない首です。
  • 解説者の対応を古事記の順に並べると、ほぼ古事記の流れに沿っています。ただし、順の逆戻りや繰り返しもあります。別天神 → 神世七代 → 神生み → 神避り → 火神被殺 → 黄泉国 → 禊 の順に重なります。
  • 第65〜80首は、確認できた資料に古事記との対応づけがありません。「対応なし」と明記した解説者もいないので、未確認の扱いです。
  • 対応づけを載せる解説者は3人。吉野信子さん（第2〜28首）、中島志保さん（第55首まで）、HIRONOMICHI（全域。「神様に解説をお願いした」という神示形式で独自説を含むため、参考扱い）。
  • 対応は解釈の一つです。原本は現存が確認されておらず、資料はすべて二次資料。楢崎皐月は古事記を参考に解読したとされるため、対応が見つかっても独立した裏づけにはなりません。

図について

図は、元資料から切り出したカタカムナ文字の渦巻き図を、白黒反転して小さくしたものです。本文との首ごとの照合は、まだ終わっていません。

この整理で確認していないこと

  • 日本書紀との対応（書紀本文は、信頼できる公的資料で確認できませんでした）。
  • 古事記の海幸山幸〜神武天皇の節（國學院大學の古事記ビューアーが未公開の範囲）。
  • 解説者の対応づけの妥当性。「解説者がそう当てている」「古事記にその神名がある」までを確認し、意味や順序の一致は評価していません。
  • 吉野信子さんの動画（第29首以降）と、中島志保さんの第56首以降の解説（公開リンクが確認できませんでした）。
  • 第14首の吉野信子さんの表にある「アマテラス・ツクヨミ・スサノオ」は、第14首の本文のどの出典にもない語です。表の置き場所の誤りかどうかは、資料から判断できません。
