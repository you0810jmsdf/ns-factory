使い方マニュアル（バイブル 月間ブロック印刷ツール）

■ 基本の流れ

  1. 左メニュー「印刷モード」で 日付あり／なし・言語 を選ぶ
  2. 日付ありは 期間（開始日・終了日）（かかる月をすべて作ります）、日付なしは 月数（枚数） を設定
  3. プレビューを確認後、PCは「印刷」、スマホは「PDFを生成」
  4. 「印刷モード」の 用紙 で印刷する用紙を選べます（選んだ用紙の説明はボタンの下に出ます）
  5. 印刷ダイアログで A4縦・「実際のサイズ（100%）」 を選ぶ

■ 日付なしモードについて

  • 年・月・日付・曜日・祝日を印刷しません。かわりに薄い透かし（デジタル風の「8」の形と、7つの曜日）を出します
  • 使う人が透かしをなぞる・塗ることで日付と曜日を決めます。月曜始まりでも日曜始まりでも、年の途中からでも使えます
  • マスは常に 6週×7列（42マス）。使わないマスはメモ欄として使えます
  • 「透かし濃さ」で見え方を調整できます。透かし自体を出したくないときは「なし（空欄）」を選んでください

■ 上下見開き（リングが上）で使う場合

  • 「印刷モード」の 使う向き で「上下見開き」を選ぶと、手帳を時計回りに90°回して（リングを上にして）使うレイアウトになります。上下の見開き1面で1ヶ月：上のページに前半3週と曜日見出し、下のページに後半3週とメモ
  • 最初の紙の表と最後の紙の裏は、罫線だけのメモページになります
  • 用紙・穴の位置は左右見開きと同じです。「📖 綴じ後プレビュー」も上下見開きで表示されます。上下見開きのときは「レイアウト」の選択は使いません
  • ※ 上下見開きは試作です。実物での組み立て確認が済んでいません

■ 用紙と面付け

  • A4を 縦向き に使い、バイブル（95×170mm）を2列×1段に2面並べます。周囲の余白（カット線の外側）は切り落とします
  • 穴は6穴（上端から 18.5 / 37.5 / 56.5 / 107.5 / 126.5 / 145.5 mm、綴じ側の端から5mm。バイブル週間・日次の旧ツールと同じ位置（実機印刷で2mm上げた値））
  • リフィルは用紙の中央に置くので、プリンターの印刷できない縁にはかかりません

■ 両面印刷の手順

  1. 「両面印刷」をON
  2. プリンターの両面設定を 「長辺綴じ」 に（縦向き用紙のため）
  3. 印刷後、周囲の余白とカット線で切り分け、画面の表示順に束ねてリングに綴じます
  4. ※ 両面の面付けは実物での組み立て確認が済んでいません。まず1か月分で試してから本番印刷をおすすめします

■ 困ったとき

  • サイズが合わない → 用紙の向き（横）と印刷倍率100%を再確認
  • iPhone/iPadでレイアウトが崩れる → 「PDFを生成」を使用
  • 機能変更点を確認したい → 「更新履歴」ボタン
