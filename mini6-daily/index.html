サポート

使い方マニュアル（Mini6 デイリー印刷ツール）

■ 基本の流れ

  1. 「印刷モード」で 日付あり／なし を選ぶ
  2. 日付ありは 期間（開始日〜終了日） の全日。日付なしは 日数（枚数）
  3. 表面をON → 印刷（またはPDF生成）。同じ用紙を戻して裏面をON → 印刷。自動両面プリンタなら「自動両面（表裏交互）」
  4. 「印刷モード」の 用紙 で印刷する用紙を選べます（選んだ用紙の説明はボタンの下に出ます）
  5. 印刷ダイアログで A4縦・「実際のサイズ（100%）」。両面は 長辺綴じ

■ 日付なしモードについて

  • 日付・年月・曜日・祝日・月カレンダーを印刷せず、日付欄にデジタル風「8」の薄い透かし、曜日欄に7つの曜日を薄く出します。なぞる・塗って使います
  • 時間軸とメモ欄はそのまま。「透かし濃さ」で見え方を調整できます

■ 上下見開き（リングが上）で使う場合

  • 「印刷モード」の 使う向き で「上下見開き」を選ぶと、手帳を時計回りに90°回して（リングを上にして）使うレイアウトになります。上下の見開き1面で1日：上のページに日付と時間軸の前半、下のページに時間軸の後半とメモ
  • 最初の紙の表と最後の紙の裏は、罫線だけのメモページになります
  • 用紙・両面設定・穴の位置は左右見開きと同じです。「📖 綴じ後プレビュー」も上下見開きで表示されます
  • ※ 上下見開きは試作です。実物での組み立て確認が済んでいません

■ 用紙と面付け

  • A4を 縦向き に使い、Mini6（80×128mm）を2列×2段に4面並べます。周囲の余白（カット線の外側）は切り落とします
  • 表面は「1日目（左穴）／3日目（右穴）」、裏面は「4日目／2日目」。切り分けると各片の表裏で1・2日目、3・4日目が対になります
  • 穴は6穴（上端から 16.3 / 35.5 / 54.7 / 73.9 / 93.1 / 112.3 mm、綴じ側の端から6.3mm。当工房の基準データ（Mini6 Refill.svg）と同じ。穴間隔19.2mm）
  • ※ 両面の面付けは実物での組み立て確認が済んでいません。まず1枚で試してから本番印刷をおすすめします

■ 困ったとき

  • サイズが合わない → 用紙の向き（横）と印刷倍率100%を再確認
  • iPhone/iPadでレイアウトが崩れる → 「PDFを生成」を使用
  • 不具合・要望 → 右下の「改善要望」ボタン
