# 画像プロキシ 設定手順（Drive写真も色替え可能にする）

作品集の写真は Google Drive（外部オリジン）から表示されるため、そのままでは
カラーシミュレーターで色替えできません（ブラウザのセキュリティ制約）。
`image-proxy.gs` を GAS にデプロイし、写真を base64 で取得することで、Drive写真も
色替えできるようになります。**GitHubへの画像保存は不要（容量ゼロ）／第三者を経由しません。**

## 手順

1. **GASプロジェクトを作成**
   - https://script.google.com を開く →「新しいプロジェクト」
   - `カラーシミュレーター/image-proxy.gs` の中身を全部貼り付けて保存

2. **ウェブアプリとしてデプロイ**
   - 右上「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」
   - 説明：`image proxy`
   - **実行ユーザー：自分**
   - **アクセスできるユーザー：全員**
   - 「デプロイ」→ 認可を求められたら許可
   - 発行された **ウェブアプリ URL（`https://script.google.com/macros/s/…/exec`）** をコピー

3. **フロントに設定**
   - `カラーシミュレーター/photo-color.html` を開き、次の行の空文字にURLを貼る：
     ```js
     let IMAGE_PROXY_URL = ''; // ← ここに /exec URL を貼る
     ```
   - 例：`let IMAGE_PROXY_URL = 'https://script.google.com/macros/s/AKfyc.../exec';`
   - コミット＆プッシュ（GitHub Pages に自動反映）

4. **動作確認**
   - 先に貼らずに試すこともできます：色替え画面のURLに `?proxy=<GAS URL>` を付けて開く
   - 作品集で作品を開き「🎨 色違いをシミュレーション」→ 外部写真でも色が変わればOK

## セキュリティ / 注意

- `image-proxy.gs` は **Googleの画像ホストのみ**取得を許可（`ALLOWED_HOSTS`）。任意URLの
  取得（オープンプロキシ化）を防いでいます。他ドメインも通したい場合はここに追記します。
- GAS の `UrlFetchApp` には1日あたりの実行回数制限があります（通常の閲覧量なら十分）。
- 画像取得は1枚ごとに数百ms〜数秒かかることがあります（base64取得のため）。
- URLを差し替えたい/無効化したいときは `IMAGE_PROXY_URL` を空にすれば、
  外部写真は「色替えできません」の案内表示に戻ります（同一オリジン写真は常に色替え可）。
