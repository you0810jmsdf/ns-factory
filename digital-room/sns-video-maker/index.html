かんたん4ステップ

無料・登録不要。使う方に合った説明を選んでください。

自分の端末にある写真から作る場合

  1. 写真を追加する「写真を読み込む・追加」を開き、「端末から写真を追加」で作品写真を選びます。写真は外部へアップロードされません。
  2. 構成・字幕・セリフを整える「使う／戻す」で使用写真を選び、「作品情報」で物語の型と長さを選びます。「① 写真の役割を提案 → ② 構成と順番を確認 → ③ カメラワークと台本を適用」の順に押すと、役割ごとに動きとセリフが変わります。必要に応じて「写真ごと」で直します。
  3. 仕上がりを確認する「音声つきプレビュー」で写真・字幕・音声を確認します。途中で止めるときは「停止」を押します。
  4. MP4で保存する英語台本は「自動ナレーション付きMP4」、日本語台本は「自分の声で録音」を使用します。初回のAI音声生成は準備に時間がかかります。

すべて無料で利用できます。ページを閉じたり再読み込みすると編集中の内容は消えるため、MP4保存まで続けて操作してください。

作品集・在庫リスト・Google Driveを使う社内運用

  1. 作品番号で読み込む「写真を読み込む・追加」を開き、作品番号を入力して「Driveから写真を表示」を押します。作品集の名称・素材・長文紹介も自動で入ります。
  2. 作品情報を確認する「作品情報」タブで作品名、素材・サイズ、長文紹介を確認します。素材欄は在庫リストの候補から修正できます。
  3. 構成と英語台本を組み直す不要写真を除外し、物語の型を選んで「① 役割を提案 → ② 順番を確認 → ③ カメラワークと台本を適用」の順に進めます。「長文を英語メモへ」を先に押しておくと、見どころメモの英文が台本の素材になります。
  4. 保存・Driveへ戻す出力設定でAI音声を選んでMP4を生成します。完成後はダウンロード、または対象作品フォルダへのDrive保存を選びます。

作品番号、作品集プリセット、在庫候補、Drive保存はN's factory独自機能です。一般利用では設定不要です。

    作品集の長文を英訳し、写真枚数分へ広げます。

    動画の構成を決める

    作品情報・見どころメモ・物語の型・演出プリセットをまとめて切り替えます。

    写真を追加すると、①提案 → ②確認 → ③適用の順で、役割・順番・動き・セリフをまとめて整えられます。

    台本作成ボタンの使い方
    1空欄を補完空の見出し・セリフだけに案を入れます。
    2メモを変換長文紹介と見どころメモを日英変換します。
    3台本を再構成除外後の使用写真だけでセリフを組み直します。

    「① 写真の役割を提案」を押すと、提案の理由と信頼度がここに表示されます。手で選んだ役割は自動処理で上書きされません。

    Instagramのフィード（ホーム・プロフィール一覧）は縦長9:16動画の上下をトリミング表示します。フィードへ投稿する動画は「4:5」を選ぶとタイトルや字幕が切れません。

    写真ごとに選んだ動き（ズームイン等）はそのままに、動く量だけを全コマまとめて強めます。プレビューにすぐ反映されます。

    動きの強さ・字幕演出・フォントをまとめて変えます。写真ごとの台本は変えません。

    AIが写真の被写体を切り抜いて単色背景に置き換えます（初回のみ約5MBのモデル読み込み。写真は端末外へ送信されません）。通常版と単色版はそれぞれ保存できます（単色版はファイル名に _solid が付きます）。

    「自動ナレーション付きMP4」で保存するとき、この声がそのまま動画に入ります。日本語台本の動画は「自分の声で録音」で音声を入れてください。

    「音声つきプレビュー」「音声だけ確認」で聞こえる声です。セリフの長さや言い回しを耳で確認するためのもので、保存されるMP4には入りません。
