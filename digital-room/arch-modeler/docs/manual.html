1. このアプリでできること

機能概要
間取り作成壁・窓・ドアをマウスで作図。複数階に対応
3D表示間取りから建物を自動で立体化。家具12種を配置
日照シミュレーション緯度経度・日付・時刻から太陽位置を計算し、影をリアルタイム表示
照度解析部屋ごとの昼光照度(lx)を計算しヒートマップ表示
構造検討（簡易）壁量計算・四分割法・偏心率・N値計算・横架材・基礎の検討書をPDF出力
3Dプリント出力縮尺模型用のSTLファイルを出力（1/50〜1/200）

2. 起動方法

コマンドプロンプト（またはPowerShell）で以下を実行します。

cd "C:\Users\nsfactory\OneDrive\レザークラフト\デジタル部\建築3Dモデラー"
npm start

初回のみ事前に npm install が必要です（インストール済み）。

4. 間取りを描く（2Dエディタ）

4-1. 作図ツール

ツール使い方
選択壁や開口部をクリックで選択。開口部はドラッグで壁に沿って移動。Deleteで削除
壁クリックで始点 → クリックで確定。そのまま連続して描けます。右クリックまたはEscで終了
窓壁の上をクリックで配置（初期値: 幅1.2m×高さ1.1m・床から0.9m）
ドア壁の上をクリックで配置（初期値: 幅0.8m×高さ2.0m）
削除壁・開口部をクリックで削除

4-2. 画面操作と寸法

  • ズーム: マウスホイール ／ 画面移動: 中ボタンドラッグ または Alt＋ドラッグ
  • グリッドは0.25m単位でスナップ。既存の壁の端点にも自動で吸着します
  • 壁には長さ(m)が常時表示。画面の上方向＝北です

4-3. 開口部の寸法変更

選択ツールで窓・ドアをクリックすると、サイドバーに「開口部の編集」欄が現れ、幅・高さ・床からの高さを数値で変更できます。

4-4. 壁の規定値

「壁の高さ」「壁の厚さ」はこれから描く壁に適用されます（既存の壁は変わりません）。

5. 階層管理（2階建て以上）

  1. 「階を追加」で2F・3F…を追加（最大制限なし。構造計算は3階まで）
  2. 「編集する階」セレクタで作図対象の階を切替
  3. 「下階を下書き表示」をONにすると下の階の壁が薄いグレーで表示され、上下階の壁位置を合わせやすくなります
家具の配置先も「編集する階」に従います。2Fに家具を置くときは先に2Fへ切り替えてください。

6. 3Dビューの操作と家具配置

6-1. カメラ操作

操作動作
左ドラッグ視点の回転
ホイールズーム
右ドラッグ視点の平行移動

6-2. 家具の配置（全12種）

  1. サイドバーの家具ボタン（ベッド・テーブル・ソファ等）をクリック
  2. 3Dビューの床をクリック → その場所に配置
  3. 家具をクリックで選択（明るくハイライト）→ ドラッグで移動
  4. Rで45°回転、Deleteで削除
磁石吸着: ドラッグ中に壁や他のパーツへ25cm以内に近づくと、磁石のように自動でぴったり吸着します（面の接触・端揃え）。家具は同じ階の壁・家具に、外構は建物の外壁・他の外構（塀の端と端など）に吸着。自由な位置に置きたいときはShiftを押しながらドラッグしてください。※斜め壁は吸着対象外。

6-3. 外構の配置（全12種）

家具と同じ操作で、敷地まわりの外構を配置できます（配置先は常に地面）。

アイテム用途・特徴
隣家（日影検討用）幅・奥行・軒高を調整できる箱。隣家の影が室内採光に与える影響を検討できます
ブロック塀・フェンス・生垣長さ・高さ調整可。境界まわりの目隠しと日影の検討に
落葉樹・針葉樹樹高調整可。木陰のでき方を確認
カーポート・駐車場（土間）駐車スペースの計画に
ウッドデッキ・物置・門柱・芝生庭まわりの計画に
  • 配置した外構をクリックで選択すると、サイドバーにサイズ調整欄が表示されます
  • 隣家・塀・樹木などの立体物は日照シミュレーションの影と照度解析の遮蔽物として反映されます
  • 外構はSTL出力（建築模型）には含まれません
南側に「隣家」を置いて冬至の正午を再生すると、隣家の影が自宅の窓にどこまでかかるかが一目で分かります。

7. 屋根の設定

形状説明
なし屋根を表示しない
陸屋根フラットな屋根（厚さ15cm）
切妻三角屋根。棟は建物の長辺方向に自動で通ります
寄棟四方に勾配のある屋根

勾配（10〜50°）と軒の出（0〜1.5m）を調整できます。屋根は最上階の外形に自動でフィットし、STL出力・日照・構造計算すべてに反映されます。

8. 日照シミュレーション

  • 日付・時刻を設定すると、太陽の位置と建物の影がリアルタイムに変わります
  • 緯度・経度: 初期値は印西市（35.83, 140.15）。任意の場所に変更可
  • 北の方位: 敷地に合わせて建物に対する北の向きを回転できます
  • ▶ 1日を再生: 朝4時〜夜20時までの太陽の動きをアニメーション
  • オレンジの弧＝その日の太陽軌跡、黄色い球＝現在の太陽、赤矢印＝北
  • 太陽高度・方位・日の出/日の入時刻はサイドバーに数値表示されます
冬至（12/22頃）と夏至（6/21頃）で比較すると、日当たりの季節差がよく分かります。

9. 照度解析（部屋ごとの明るさ）

  1. 3Dビューで日付・時刻を設定
  2. 「照度を計算」をクリック → 壁で囲まれた部屋を自動検出し、数秒で計算完了
  3. 床にヒートマップ（青＝暗い → 黄＝明るい・対数スケール）と部屋番号が表示
  4. サイドバーに部屋ごとの平均・最低・最高照度(lx)と面積を表示
照度の目安用途
300〜750 lx読書・勉強・調理
150〜300 lx団らん・食事
50〜150 lx廊下・収納

晴天時の直達日光＋天空光の簡易計算です。室内反射光を含まないため実際よりやや暗めに出ます。 隣家・塀・樹木などの外構も遮蔽物として計算されます。間取りや外構を変更するとヒートマップは消えるので再計算してください。 計算時間は数秒〜十数秒（外構が多いほど長くなり、計算中は画面が一時停止します）。

10. 壁量チェックと構造検討書

10-1. クイックチェック

  1. 「屋根の重さ」（金属・スレート＝軽い／瓦＝重い）と「壁倍率」を設定
  2. 「壁量を計算」→ サイドバーに階・方向ごとの充足率と判定が表示

10-2. 構造検討書（全12章）の作成

  1. 建物名称・所在地（任意）と地耐力を設定
  2. 「計算書を作成（印刷/PDF）」→ 別ウィンドウに検討書が開く
  3. 上部の「印刷/PDF保存」ボタンからPDF化
章内容
1. 建物概要名称・階数・屋根・床面積・地耐力
2〜3. 必要壁量地震力（床面積×係数）・風圧力（見付面積×50）
4〜5. 存在壁量と判定壁1枚ごとの内訳表と充足率判定
6. 四分割法建物両端1/4ゾーンの壁配置バランス
7. 偏心率重心と剛心のズレ（Re≦0.3で適合）
8. N値計算柱頭柱脚の接合金物選定（告示1460号）
9. 横架材部屋スパンから梁せいの目安
10. 基礎接地圧チェックと基礎形式の提案
11〜12. 配置図・総合判定耐力壁配置図（重心G・剛心K表示）と判定一覧
構造検討書は簡易計算による参考資料です。確認申請に使用するには建築士による検証と正規図書の作成が必要です。

11. 3Dプリント用STL出力

  1. 3Dビューの「3Dプリント出力」で縮尺（1/50〜1/200）を選択
  2. 「壁厚の最小保証」: 縮尺後に壁が薄くなりすぎる場合、印刷可能な厚みまで自動補強（推奨2mm）
  3. 床スラブ・屋根を含めるかチェックで選択
  4. 「STLエクスポート」→ ダウンロードフォルダに保存。印刷サイズ(mm)が表示されます
縮尺8m×6mの家の模型サイズ壁厚15cmの模型厚
1/50約160×120mm3.0mm（そのまま印刷可）
1/100約80×60mm1.5mm（最小保証2mm推奨）
1/200約40×30mm0.75mm（最小保証2mm必須）

12. データの保存と読込

  • 自動保存: 操作のたびに自動保存され、次回起動時に復元されます
  • 保存(JSON): 間取りデータをファイルに書き出し（ダウンロードフォルダ）
  • 読込(JSON): 保存したファイルを読み込み。旧バージョンの形式も自動変換
  • サンプル読込: 2階建て・切妻屋根のサンプル住宅を読み込み
  • 全消去: すべてのデータを消去（確認ダイアログあり）

13-2. よくある質問（FAQ）

質問回答
照度解析で「部屋が見つかりません」と出る壁が完全に閉じていません。壁の端点同士をスナップで接続してください
計算書のウィンドウが開かないポップアップブロックを許可してください（Electron版では通常発生しません）
STLが薄すぎて印刷に失敗する「壁厚の最小保証」を2mm以上に設定してください
2Fの壁が1Fとずれる「下階を下書き表示」をONにし、グレーの線に合わせて描いてください
影が表示されない時刻が夜間（太陽高度マイナス）になっていないか確認してください
斜めの壁は使える？作図・3D表示は可能ですが、壁量計算では集計対象外です（注記が出ます）

13-3. 免責事項
