静電気対策（最初にやる）

  1. 作業の前に、塗装されていない金属（ドアノブ、ケースの骨組み）を素手で触る。
  2. 部品を触る前に、ときどき同じことを繰り返す（席を立って戻ったら必ず）。
  3. じゅうたんの上・セーター姿で作業しない。
  4. 基板はふちを持つ。裏の部品や金色の端子を指でこすらない。
  5. 部品は使う直前まで静電気防止袋（銀色の袋）から出さない。
メーカーの注意書き（MSI 公式マニュアル 安全情報より要約）：静電気防止バンドの使用が望ましい。無い場合は他の金属に触れて放電してから扱う。基板は端を持ち、使わないときは静電気防止袋か静電防止マットの上に置く。電源を入れる前に、ネジや金属片が基板の上や中に落ちていないか確認する。確信度：高

ネジの見分け方

袋から全部出して、種類ごとに小皿に分けるところから始めます。長さより「太さと山の粗さ」で見ます。

ZALMAN T3 PLUS には必要なネジが同梱されています。足りない・回らないときは、無理に回さずに別の種類を試すのが鉄則です。確信度：中

④ CPU を付ける（三角の印とレバー）

手順

  1. ソケット横の金属レバーを、横に少しずらしてから上に起こす（垂直まで）。
  2. CPUを箱から出す。裏の金色のピンには絶対に触らない。側面をつまんで持つ。
  3. CPUの角の▲印と、ソケットの角の▲印を同じ側に合わせる。
  4. 真上からそっと置く。押し込まない。向きが合っていれば自重で沈む。
  5. レバーをゆっくり下ろす。最後に少し力が要るのは正常。
ここだけは慎重に。ピンが曲がると修理できません。「押し込む」感触が出たら必ず手を止めて、持ち上げて向きを確かめる。
豆知識：AM4ソケットは「ZIF（力を入れずに挿す）」という仕組みで、レバーが上がっていればCPUは自重で入ります。入らないのは、向きが違うか、レバーが十分上がっていないかのどちらかです。確信度：高

⑤ 純正クーラーを付ける（グリスは塗布済み）

グリス：Ryzen 5 5600GT BOX に付属するクーラーは、底面に灰色のグリスがあらかじめ塗ってあります。拭き取らない・買い足さない。透明な保護フィルムが貼ってあれば剥がします。確信度：高（AMD純正クーラーの仕様）

付けるとき

  1. 箱を開けて、クリップ式（金具とレバー）か、ネジ式（4本のネジ）かを確かめる。
  2. クリップ式：マザーボードの黒いプラスチック枠はそのまま。片側のツメに金具を掛け、反対側を掛け、レバーを倒す。
  3. ネジ式：黒い枠を先に外す（ネジ2本×2）。クーラーを載せ、対角の順に少しずつ4回に分けて締める。
  4. クーラーの電源コードを CPU_FAN1（4ピン・ソケットの右上）に挿す。
  5. クーラーを軽く左右に揺すって、ぐらつかないことを確認する。
MSI 公式マニュアルの注意：「ネジ式のヒートシンクを取り付ける場合は、先に固定枠（リテンションモジュール）を外すこと」。確信度：高
向き：コードが CPU_FAN1 に無理なく届く向きに載せます。一度付けてから回すと、グリスがずれて付け直しになります。
予備のグリスはありません。いったん外すと塗り直しが必要になります。付け直す可能性が心配なら、小袋のCPUグリス（400円前後）を1つ用意しておくと安全です。

⑥ メモリと M.2 SSD

スロットの数：MSI B550M-A PRO の DDR4 スロットは 2本（DIMMA1／DIMMB1）、最大64GBです。4本ある機種のような「1本飛ばしで挿す」判断は不要で、16GB×2枚を両方に挿せば自動的にデュアルチャネルになります。確信度：高（MSI公式仕様）
M.2 スロット：このマザーボードの M.2 は M2_1 の1本だけ（2242/2260/2280 対応、B550ではPCIe 4.0）。Lexar NM610 PRO は 2280（長さ80mm）なので、いちばん遠いネジ穴を使います。確信度：高（MSI公式仕様）

⑦ ケースに入れる（I/Oシールド・スタンドオフ・電源）

順番

  1. ケースの両側のパネルを外す（背面のネジ）。裏側も外して、配線を裏に通せるようにする。
  2. I/Oシールド（銀色の板）を内側からはめる。四隅を押すとパチンと入る。先にやる。
  3. スタンドオフ（六角の柱）の位置を、マザーボードの穴と見比べる。穴の無い所の柱は外す。
  4. 端子をI/Oシールドの穴に通しながら基板を置き、6本のネジで仮止め → 対角の順に本締め。
  5. 電源ユニットをケース下部に入れ、背面から太いネジ4本で固定する。
電源の向き：ケースの底に通気の穴とフィルターがあればファンを下向き、無ければ上向きにします。ASRock PRO-650B は奥行き140mm・120mmファン。ZALMAN T3 PLUS は ATX電源対応なので、ドライブケージを外さずに入るはずです。確信度：中（実測は組むときに確認） 入らなければドライブケージをネジで外します（3.5インチHDDは使いません）。
やりがちな失敗：I/Oシールドを入れ忘れる／柱の位置がずれたまま無理にネジを回す／ネジを締めすぎて基板を反らせる。手応えが出たら止める。

⑧ 電源ケーブルをつなぐ（24ピンと4ピン）

この機種でいちばん間違えやすいところ。ASRock PRO-650B から出ている CPU用ケーブルは EPS 12V 4+4ピン ×1（ASRock公式仕様）。いっぽう MSI B550M-A PRO の受け口 CPU_PWR1 は 4ピン（MSI公式マニュアル）。2つを合体させて8ピンにしても挿さりません。片側4ピンだけを挿します。確信度：高

つなぐもの（この4本だけ）

#ケーブル挿す場所目印
124ピン（いちばん太い）ATX_PWR1（基板の右端）ツメがカチッと鳴るまで
24+4ピンのうち片側4ピンCPU_PWR1（基板の左上）すっと入る方を使う。逆向きは入らない
3CPUクーラーのファンCPU_FAN15ページで挿し済み
4ケースファンSYS_FAN1ファン端子はここ1つだけ（下の注意）

SSDはM.2なのでSATAケーブルも電源ケーブルも不要です。PCIe補助電源（6+2ピン）も使いません。余ったケーブルは束ねて裏側へ逃がします。

ケースファンは2基、基板の端子は1つ。このマザーボードのファン端子は CPU_FAN1 と SYS_FAN1 の2つだけで、ケースファン用は SYS_FAN1 の1つです。T3 PLUS には120mmファンが2基付いているので、①1基だけつなぐ（展示用途ならこれで十分）②分岐ケーブル（数百円）で2基つなぐのどちらかにします。確信度：中（端子数はMSI公式図で確認。ファン側の端子形状は現物で確認）
安全：電源ユニット背面のスイッチは、配線が全部終わるまで「○（OFF）」のままにしておきます。

⑩ 最初の電源投入と BIOS の確認

手順

  1. プロジェクター（またはテレビ）をマザーボード背面のHDMIにつなぐ。付属のHDMIケーブルは約1m。
  2. キーボード K120 を背面USBに挿す。
  3. 電源コードをつなぎ、電源ユニット背面のスイッチを「I」にする。
  4. ケース前面の電源ボタンを押す。
  5. 画面が出たら Delete キーを連打して BIOS 画面へ入る。

BIOSで確認する

項目正しい表示違うときは
CPUAMD Ryzen 5 5600GT型番が出ない → 12ページ
メモリ32768MB（32GB）16GBなら1枚が挿さっていない（6ページ）
ストレージLexar の名前が出る出ない → M.2の挿し直し
BIOSバージョン7C96v2B 以降これより古い → 12ページ
CPU温度放置で40〜50℃くらい急に上がる → クーラーの密着を疑う

やっておく設定

  1. A-XMP を有効にする（メモリが本来の DDR4-3200 で動く）。入れた瞬間に起動しなくなったら、電源を切って CMOS クリア（JBAT1 の2本をドライバーの先で5秒つなぐ）→ A-XMP は切ったまま使う。定格の 2666 でも展示には支障ありません。確信度：中（メモリがMSIの動作確認リストに載っているかは未確認）
  2. Windows の USBメモリを挿し、起動順の1番目にする。
  3. F10 で保存して再起動。

⑪ Windows 11 の導入と、Wi-Fi・Bluetooth の確認

ネット接続：自宅で作業する間は有線LANをつないでおくと確実です（セットアップ中にネットを求められます）。
「このPCは Windows 11 の要件を満たしていません」と出たら。TPM 2.0 とセキュアブートがBIOSで無効になっているのが原因です。BIOSに入って次の2つを入れてから、もう一度インストールします。
① Settings → Security → Trusted Computing → AMD fTPM switch を「AMD CPU fTPM」に
② Settings → Advanced → Windows OS Configuration → Secure Boot を Enabledに（起動モードは UEFI）
確信度：中（MSIのBIOS世代によって項目名と場所が少し違います）

インストール

  1. 付属のUSBメモリを背面USBに挿して電源を入れる。「Press any key to boot from USB」でキーを押す。
  2. 言語＝日本語 →「今すぐインストール」。
  3. プロダクトキーを入力（パッケージ内のカード。捨てずに保管）。
  4. 「Windows 11 Home」を選ぶ。
  5. 「カスタム：Windowsのみをインストール」→ 未割り当ての1TB を選んで次へ。パーティションは作らなくてよい。
  6. 地域＝日本、キーボード＝Microsoft IME。画面の指示どおり進める。
  7. デスクトップが出たらUSBメモリを抜く。

ドライバーと更新

  1. Windows Update を「更新プログラムのチェック」で全部当てる（何度か再起動）。
  2. MSI公式サイトから B550M-A PRO のチップセットドライバーを入れる。
  3. AMD公式サイトから Radeon グラフィックスドライバーを入れる。

USB Wi-Fi アダプターと Bluetooth

  1. 有線LANを抜き、USB Wi-Fiアダプターを挿して自宅のWi-Fiにつながるか試す。
  2. 続けてスマホのテザリングにもつながるか試す（外に持ち出すときはこれが頼りになる）。
  3. 設定 →「Bluetoothとデバイス」でBluetoothのスイッチが出るか確認する。スピーカーを使うならここでペアリングまでやる。
「ドライバー不要」は出品者の表記で、まだ検証していません。確信度：低 つながらない場合は、付属CDではなくメーカー配布のドライバーをダウンロードして入れることになります。使う前に自宅で必ず試しておくこと（持ち出し先で初めて挿すのは危険）。

⑫ 映らないとき／BIOSが古いとき／3Dマップで仕上げの確認

BIOS が古くて 5600GT で起動しないとき

この機種に Flash BIOS ボタンはありません。MSI公式マニュアルの背面端子一覧にも、MSIサポートページにも記載がありません（背面は HDMI／DVI-D／PS2×2／USB3.2×4／USB2.0×2／LAN／音声×3 のみ）。CPUを載せずにUSBメモリだけでBIOSを書き換える方法は、この基板では使えません。確信度：高
※ 購入リストの「Flash BIOSボタンあり／USBメモリ GIGASTONE に MSI.ROM を入れて更新」は、この基板には当てはまりません。
状況やること
画面が出て BIOS に入れる（＝CPUは認識されている）M-FLASH で更新：別PCでMSI公式から最新BIOS（7C96…）をダウンロード→解凍→USBメモリ（FAT32）の一番上に置く→BIOSで「M-FLASH」→ファイルを選ぶ→完了まで電源を切らない
まったく画面が出ず、EZ Debug LED の CPU が点いたままBIOSが5600GT（7C96v2B以降が必要）に未対応の可能性。対応する古いCPU（Ryzen 3000シリーズなど）を一時的に借りて起動し、M-FLASHで更新する／購入店（ツクモ）にBIOS更新を相談する確信度：中

仕上げ：3Dマップを動かして、性能を確かめる

  1. ブラウザで 3Dマップ（https://communitybankinzai.github.io/cbi-site/metaverse/?mode=musashiya）を開く。
