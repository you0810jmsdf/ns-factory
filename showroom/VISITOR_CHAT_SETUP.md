# 来店者チャット（お客様同士の会話）設定手順

3Dショールームに「👥 みんなのチャット」を追加するためのGASデプロイ手順です。
来店したお客様同士が、**アバター（動物の絵文字）＋ニックネーム**で気軽に会話できます。

## 仕組み

- 入室時にアバターとニックネームを選択（識別用）
- 在室者リストと直近メッセージ（最大50件）を数秒おきに同期
- データはGASの一時キャッシュのみに保存（**スプレッドシート不要・個人情報は保存されない**。
  在室情報は離脱後約60秒、メッセージも最大6時間で自動消滅）
- 連投制限（2秒に1回）・文字数制限（120字）・禁止ワード・URL投稿禁止つき

## デプロイ手順

1. https://script.google.com →「新しいプロジェクト」（名前例: `nsfactory-visitor-chat`）
2. `showroom/visitor-chat.gs` の中身を全部貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**
4. 発行された **ウェブアプリURL（/exec）** をコピー
5. `showroom/index.html` の設定に貼り付け:
   ```js
   window.SHOWROOM_CONFIG = {
     chatApi: '',
     visitorChatApi: 'ここに /exec URL',
   };
   ```
6. コミット＆プッシュ（GitHub Pages反映後、ショールーム左下に「👥 みんなのチャット」ボタンが出ます）

## 動作確認（デプロイ前でも可）

URLに `?vchat=<GASのURL>` を付けてショールームを開くと、その場で試せます。

## 運用メモ

- **URL未設定のときはボタン自体が表示されません**（安全に無効化）
- 禁止ワードは `visitor-chat.gs` の `NG_WORDS` に追記できます
- 荒らし対策を強化したい場合：`SAY_INTERVAL_MS`（連投間隔）や `MSG_MAX_LEN` を調整
- 完全に止めたいとき：GASのデプロイをアーカイブするか、`visitorChatApi` を空に戻す
