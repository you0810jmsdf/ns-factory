# ふるさと納税 返礼品への AI相談 案内ガイド

返礼品にQRカードを同梱し、寄付者を **オーダー相談AI**（`hearing-ai.html`）へ誘導するための、
カード作成・文面・**制度（規約）確認**の運用メモです。

関連ツール:
- 同梱カード作成（印刷用）: `order_estimate/furusato-card.html`
- オーダー相談AI: `order_estimate/hearing-ai.html`

---

## 1. 全体の流れ（おすすめ運用）

```
返礼品を発送
   └─ 同梱カード（QR）を同封
        └─ 寄付者がスマホでQRを読み取る
             └─ オーダー相談AIが用途をヒアリング
                  └─ 発注票（仕様シート）が完成
                       └─ 「工房へ送る文面」を寄付者が送信 / 工房が内容確認
                            └─ 職人が正式なご案内（※課金の扱いは下記2を厳守）
```

ポイント: **QRカードは「仕様を決める入口」**。カードだけで完結させず、
最終確認は必ず人（職人）が行う設計にしておくと、制度上も品質上も安全です。

---

## 2. ⚠️ 制度（規約）で必ず確認すること

ふるさと納税は「寄付への返礼」であり、通常のEC販売とは扱いが異なります。
**AI導線を作る前に、下記を自治体担当・利用ポータル（さとふる/楽天/ふるなび等）に確認してください。**

### 必須チェックリスト

- [ ] **返礼品の範囲**：返礼として提供するのは「オーダー品そのもの」か「オーダー枠（引換）」か。返礼の内容と寄付額の対応が明確になっているか。
- [ ] **区域外への誘導の可否**：QRの飛び先（自社サイト/LINE）へ誘導することがポータル規約・自治体ルールで禁止されていないか。
- [ ] **追加課金（上乗せ販売）の扱い**：AIヒアリングの先で「返礼品の範囲を超える有料オプション」を案内・決済して良いか。**原則、寄付と別の売買を返礼品に紛れ込ませるのは避ける**。やる場合は必ず事前承認を得る。
- [ ] **決済導線を同梱物に載せないこと**：カードに価格・振込先・購入ボタン等の決済情報を**書かない**（相談・仕様決めまでに留める）。
- [ ] **個人情報の取り扱い**：寄付者情報とオーダー内容の紐付け方法（誰がどう照合するか）を決め、プライバシー面で問題ないか。
- [ ] **景品表示・寄付額表示**：カードや案内に「◯円相当」等の断定的表示をしない。価格は「概算・目安」に留める（AI側も同方針）。
- [ ] **地場産品基準**：返礼品が総務省の基準（地場産品等）を満たしているか（オーダー品でも同様）。
- [ ] **納期・キャンセル**：オーダーゆえの長納期・変更/キャンセル条件を、返礼品説明とカードで齟齬なく案内できているか。

### 安全な設計 / 避けたい設計

| ✅ 安全 | ⚠️ 要確認・避けたい |
|---|---|
| 寄付の返礼として「オーダー枠」を提供し、**仕様決めだけAIで行う** | AI経由で返礼範囲を超える商品を**その場で追加販売・決済** |
| カードは相談・仕様確認まで（価格は目安） | カードに**振込先・購入リンク・確定価格**を掲載 |
| 最終確認は職人が実施 | AIが**自動で売買を確定** |

> まとめ: 「**寄付でオーダー枠を返礼 → 仕様をAIで詰める**」はほぼ問題なし。
> 「**AI経由で上乗せ販売**」はポータル/自治体の規約次第なので、必ず事前確認。

## 3. 同梱カードの作り方（furusato-card.html）

1. `order_estimate/furusato-card.html` を開く（公開後は
   `https://you0810jmsdf.github.io/ns-factory/order_estimate/furusato-card.html`）。
2. **案内先URL** を確認（既定はオーダー相談AI。LINE公式に変更も可）。
3. **文面プリセット**（丁寧／やさしい／簡潔）を選ぶか、自由に編集。
4. **カードサイズ**（名刺 91×55mm ／ ハガキ 100×148mm）を選ぶ。
5. QRが汚れ・小サイズに不安があれば **補正レベル Q/H** に。
6. 「🖨 印刷 / PDF保存」→ 名刺用紙 or ハガキ用紙に印刷。
   - 印刷ダイアログは「余白なし/最小」、用紙に合わせて倍率調整。

QRは端末内で生成（外部サービス非依存）。**印刷前に必ず実機のカメラで読み取りテスト**を行ってください。

## 5. よくある質問（内部メモ）

- **Q. QRの飛び先はサイトとLINEどちらが良い？**
  A. 相談を確実に記録・返信したいなら **LINE公式**。まず体験してもらう入口なら **オーダー相談AI** が手軽。カードのURLを差し替えるだけで両対応。
- **Q. 返礼品の種類が増えたら？**
  A. カードのURLは共通のままでOK。オーダー相談AIが商品選択から分岐します（システム手帳・財布・キーケース等に対応済み）。
- **Q. 公開URLが404になる**
  A. 新ページは `main` ブランチにマージ後に公開されます（GitHub Pages は main 配信）。
