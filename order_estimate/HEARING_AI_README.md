# オーダー相談AI（ヒアリングAI）— 使い方と「知識の覚えさせ方」

システム手帳フルオーダーのヒアリングをAIに行わせる試作ページです。
公開URL（GitHub Pages）: `order_estimate/hearing-ai.html`

## 2つのモード

| モード | 必要なもの | 中身 |
|---|---|---|
| **ガイド対話モード**（既定） | なし・すぐ動く | 工房の実データに沿って順番に質問し、根拠付きで提案。最後に**発注票**を自動生成 |
| **AI会話モード**（任意） | Anthropic APIキー | 決まった質問に縛られず自由に相談できるライブAI。同じ知識ベースを使う |

- APIキーは**その端末のブラウザ内（localStorage）だけ**に保存され、Anthropic の API 以外へは送信されません。
- キー無しでも、ガイド対話モードで最後まで発注票を作れます。まずはこちらで運用できます。

## 出力

ヒアリングが終わると、以下を含む**発注票（ヒアリングシート）**が出ます。
- 用途 / 持ち運び / サイズ / リング / モデル / 革色 / ステッチ / 名入れ / 予算 / 納期
- 概算の目安レンジ（正確な額は既存の見積りツールと職人確認で確定）
- 「発注票をコピー」「工房へ送るLINE文面をコピー」「正確な見積りへ」ボタン

## 「専門知識」の覚えさせ方 ＝ ここを編集するだけ

`hearing-ai.html` の先頭にある **`const KB = {...}`**（知識ベース）を書き換えれば、
AIの受け答えとガイド対話の両方に即反映されます。**再学習（ファインチューニング）は不要**です。

- `KB.sizes` … サイズと用途ヒント（`size-baseprice.csv` に対応）
- `KB.rings` / `KB.ringAdvice` … サイズ別リング径（`ring-price-stock.csv` に対応）
- `KB.models` … 作り（Simplist / N-Pad 等。`brand-price.csv` に対応）
- `KB.leatherColors` / `KB.leatherNote` … 革色の提案
- `KB.stitchInStock` / `KB.stitchAdvice` … 在庫ステッチ（`stitch-thread-stock.csv` の在庫TRUE）
- `KB.price` … 概算レンジ（`settings.csv` の時給・単価に対応）

価格や在庫が変わったら、この `KB` を直すだけ。値上げのたびに学習し直す必要はありません。
AI会話モードの人格・話し方・ルールは、同ファイルの `SYSTEM_PROMPT` で調整できます。

## ふるさと納税・返礼品への案内

返礼品にこのページのQRコードを同梱すれば、寄付者がその場でオーダー内容を相談 →
仕様が固まった発注票を工房が受け取れます。
※「寄付の返礼枠 → 仕様をAIで詰める」設計は安全ですが、AI経由で**別途上乗せ販売**へ
つなぐ場合はポータル/自治体の規約確認が必要です。
